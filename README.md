# Paraphin 🔬

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![Python](https://img.shields.io/badge/python-100%25-brightgreen.svg)](https://github.com/1g0g0r/paraphin)

## 📝 Описание
- 📊 Моделирование двухфазной фильтрации нефти
- 🌡️ Учет неизотермических процессов
- 🔄 Расчет процессов кольматации (оседание парафиновых частиц в капяллярах)
- 🌊 Моделирование суффозии (вынос парафиновых частиц из капилляров)
- 📈 Двумерное представление результатов (интерактивные plotly графики)

## 📚 Математическая модель
### Основные уравнения:
  - Уравнения сохранения массы (воды, нефти, парафина)
  - Уравнения движения (закон Дарси)
  - Уравнение энергии
  - Уравнения фазовых переходов парафина
### Численные методы:
  - Метод IMPES (неявный по давлению, явный по насыщенности)
  - Регулярная прямоугольная сетка
  - Метод конечных объемов
### Литература и источники
  - NikiforovAI_Ljm_2022_rus - постановка задачи и описание основных принципов
  - Interpretation of Well-Block Pressures in Numerical Reservoir Simulation With Nonsquare Grid Blocks and Anisotropic Permeability - учет скважин по формуле Писмана
  - Model-Assisted Analysis of Simultaneous Paraffin and Asphaltene Deposition in Laboratory Core Tests - исследование кольматации парафиновых отложений

## 📋 Требования
Проект использует:
- Python 3.12  
- Необходимые библиотеки указаны в requirements.txt

## 🏗️ Структура проекта
`paraphin/`  
┌─── `start.py` - модуль для запуска расчета  
├─── `graphs.py` - модуль визуализации результатов 
├─── `paraphin/` - пакет с модулями для решения задачи  
│ &emsp;├─── `constants.py` - модуль с константами  
│ &emsp;├─── `solver.py` - модуль с основными методами и полями данных  
│ &emsp;├─── `equations/` - папка с реализацией решений уравнений  
│ &emsp;│ &emsp;├─── `Pressure.py` - неявное решение уравнения для давления  
│ &emsp;│ &emsp;├─── `Qp_m_k.py` - вычисление скорости отложения парафина, множителей проистости и проницаеммости  
│ &emsp;│ &emsp;├─── `Saturation.py` - явное решение уравнения для насыщенности  
│ &emsp;│ &emsp;├─── `Temperature.py` - явное решение уравнения для температуры  
│ &emsp;│ &emsp;├─── `Velocity_h.py` - вычисление толщины осадочного слоя, скоростей блокирования и изменения радиуса капилляра  
│ &emsp;│ &emsp;└─── `Wps_Wp.py` - решение уравнений для концентрации взвешенных частиц и растворенного парафина  
│ &emsp;└───  `utils/` - папка с дополнительными модулями  
│ &emsp;&emsp;&emsp; ├───  `fluids_correlations.py` - зависимости свойств потока от температуры (пока что не используется)  
│ &emsp;&emsp;&emsp; ├───  `phase_f.py` - функции ОФП
