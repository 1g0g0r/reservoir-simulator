# Сравнение paraphin с MRST

Проверка гидродинамической части симулятора (давление, насыщенность, температура, скважины) по MRST 2024a —
MATLAB Reservoir Simulation Toolbox (SINTEF), запущенному в GNU Octave. Каждый тест сравнивает свежий расчет
paraphin с **эталоном MRST, сохраненным в файле** `data/<тест>.npz`: Octave для самих тестов не нужен, он нужен
только чтобы снять или переснять эталон.

## Что лежит

| Файл | Назначение |
|---|---|
| `test_two_phase_impes.py` | двухфазная задача `start.py` против MRST `incomp` — та же схема IMPES |
| `test_two_phase_implicit.py` | та же задача против полностью неявного MRST `ad-blackoil` (как `mrst_test.m`) |
| `test_rate_control.py` | нагнетательная на заданном дебите (режим `q` в `add_well`) против обоих решателей MRST |
| `test_heterogeneous.py` | логнормальное поле проницаемости против обоих решателей MRST |
| `test_thermal.py` | неизотермическая фильтрация: закачка холодной воды против MRST `geothermal` |
| `mrst_two_phase_impes.m`, `mrst_two_phase_implicit.m`, `mrst_rate_control.m`, `mrst_heterogeneous.m`, `mrst_thermal.m` | MATLAB-код MRST своего теста: сетка, порода, флюид, скважины, начальное состояние, решатель |
| `mrst_start.m` | постановка (из JSON теста или числа `start.py` по умолчанию) и запуск MRST: `startup.m`, модули, исправление для Octave |
| `mrst_run.m` | расчет по времени (`incomp`: incompTPFA + explicitTransport; `ad`: simulateScheduleAD) и сбор дебитов и полей |
| `mrst_output.m` | запись результата в JSON для теста (графики MATLAB-код не строит) |
| `common.py` | постановка из `constants.py`, запуск octave-cli и paraphin, эталоны, метрики, таблицы, рисунки |
| `worker.py` | рабочий процесс: расчет paraphin в копии пакета (`tests/_patched_copy.py`) |
| `data/*.npz` | эталоны MRST (появляются после `--mrst`) |
| `mrst_test.m` | первый вариант сравнения (2025): старые константы, фазы переставлены — фаза MRST `W` несет свойства нефти |

## Тесты

Общая постановка — `start.py` без парафина и теплообмена с кровлей и подошвой: пласт 200x200x10 м, k = 0.2 Д,
m = 0.3, ОФП Кори n = 2 на [S_min, S_max] = [0.18, 0.70], μ_o = 5.77 сП и μ_w = 0.40 сП при 70 °C, нагнетательная
в ячейке (0, 0) на 150 бар, добывающая в противоположном углу на 50 бар, обе — четверть скважины по Писману
(`mult = 0.25`, в MRST — `WI *= 0.25`; r_e = 0.14·√(hx² + hy²) у обоих), 2000 сут — до обводненности ~0.98. Числа
берутся из `constants.py` и сохраняются в эталоне: изменился `constants.py` — тест пропускается с просьбой переснять
эталон.

| Тест | Сетки | MRST | Что сравнивается | Допуски | Время теста / эталона |
|---|---|---|---|---|---|
| `test_two_phase_impes` | 20, 40, 75; native и flooded | `incomp`: incompTPFA + explicitTransport, давление раз в 0.25 сут | дебиты, обводненность, прорыв, КИН, поля S и p, соглашение о подвижности закачки | L2 суточной приемистости ≤ 2 %, дебита нефти ≤ 3 %, накопленной нефти ≤ 0.5 %; ср. \|Δобв.\| ≤ 0.005; прорыв ±10 сут; ср. \|ΔS\| ≤ 0.005, max ≤ 0.08; Δp ср.кв. ≤ 1 бар, max ≤ 2 бар | ~10 мин / ~25 мин |
| `test_two_phase_implicit` | то же | `ad-blackoil`, неявный Эйлер, шаг 1 сут | то же | те же | ~10 мин / ~50 мин |
| `test_rate_control` | 40 | оба | забойное давление нагнетательной, дебит нефти, обводненность, поля | закачка — тождественно; L2 забойного (от 30 сут) ≤ 2 %; остальное как выше | ~2 мин / ~25 мин |
| `test_heterogeneous` | 40 | оба | то же, что двухфазная; поле k одно у обоих (`perm_field`, зерно 1) | как выше, max \|ΔS\| ≤ 0.1 | ~2 мин / ~25 мин |
| `test_thermal` | 20, 40; 1000 сут | `geothermal` (GeothermalModel), шаг 1 сут | приемистость, температура на добывающей, поля T и p, нагрев трением | L2 приемистости ≤ 5 %; ΔT на добывающей ≤ ΔT_тр + 1 K; поле T: ср. \|ΔT\| ≤ ΔT_тр, max ≤ ΔT_тр + 1 K; к 1000 сут ср. ΔT = (Pw − p)/(ρ_w c_w) ± 15 %; Δp ср.кв. ≤ 2, max ≤ 4 бар | ~3 мин / ~1 ч |

Варианты начального состояния: **native** — как в `start.py`; **flooded** — ячейка нагнетательной заранее промыта
(S = S_max), тогда соглашения о подвижности закачки (ниже) совпадают.

Каждый файл — несколько отдельных проверок: дебиты, обводненность, поле насыщенности, поле давления, забойное
давление, температура — падает только та, где расхождение вышло за допуск, и в сообщении перечислены все прогоны и
сутки, где это случилось. Допуски поставлены с запасом ~2 раза по фактическим расхождениям (раздел «Результаты»);
у температуры — по нагреву трением ΔT_тр = (Pw − Po)/(ρ_w c_w) ≈ 2.4 K, которого нет у paraphin.

Все рисунки строит Python-тест — по сохраненным расчетам MRST (`data/<тест>.npz`) и свежему расчету paraphin;
MATLAB-код только считает. Таблицы показателей и расхождений пишутся в `outputs/mrst/<тест>.md` (и в stdout с
`-s`), рисунки — в
`outputs/mrst/figures/<тест>_*.png`:
- `*_rates_*` — дебиты, обводненность, забойное давление, температура на добывающей по суткам: paraphin — линия,
  MRST — полые маркеры поверх нее (видны обе кривые даже при полном совпадении);
- `*_isolines_*` — изолинии S_w, p и T на одних уровнях: paraphin — сплошные с подписями, MRST — штриховые;
- `*_profiles_*` — профили полей по диагонали от нагнетательной к добывающей, в те же сутки;
- `*_maps_*` — карты S_w, p (T) на 500-е (в тепловом — 250-е) сутки: paraphin и MRST в одной шкале и их разность;
- `test_heterogeneous_perm.png` — поле проницаемости, общее для обоих кодов.

## Как запускать

```bash
python -m pytest tests/mrst_tests -s                    # все сравнения по готовым эталонам
python -m pytest tests/mrst_tests/test_thermal.py -s    # одно
python -m tests.mrst_tests.test_thermal --mrst          # снять (переснять) эталон одного теста
```

Без эталона тест пропускается (`нет эталона ...: python -m tests.mrst_tests.<тест> --mrst`), поэтому в обычном
`python -m pytest tests` он ничего не стоит, пока эталоны не сняты. Два двухфазных теста в одном сеансе pytest
считают paraphin один раз.

### Octave и MRST

Нужны GNU Octave (проверено 10.3.0) и MRST 2024a (https://www.sintef.no/projectweb/mrst/ — архив распаковать куда
угодно). Пути задаются переменными окружения, по умолчанию — установка на этой машине:

| Переменная | По умолчанию |
|---|---|
| `OCTAVE` | `C:\Program Files\GNU Octave\Octave-10.3.0\mingw64\bin\octave-cli.exe` |
| `MRST_ROOT` | `C:\Program Files\GNU Octave\Octave-10.3.0\mrst-2024a` (каталог со `startup.m`) |

У каждого теста свой MATLAB-код `mrst_<тест без test_>.m` — функция `(case_file, out_file)`. На каждый прогон
`common.run_mrst` пишет постановку `outputs/mrst/<имя>.case.json` и запускает без графики, например

```bash
octave-cli --no-gui --eval "addpath('<репозиторий>/tests/mrst_tests'); mrst_thermal('<имя>.case.json', '<имя>.json')"
```

Устройство каждого `mrst_*.m` одинаковое: `mrst_start(case_file)` читает постановку `jsondecode`, выполняет
`startup.m` из ее поля `mrst_root` (или `MRST_ROOT`, если MRST еще не запущен), подключает модули
`incomp ad-core ad-blackoil ad-props compositional geothermal`; дальше в самом файле теста — сетка `cartGrid`,
порода `makeRock`, флюид (`initCoreyFluid` для `incomp`, `initSimpleADIFluid` + модель для `ad`, `addThermal*Props`
+ `GeothermalModel` для температуры), скважины `verticalWell` с WI·0.25, начальное состояние; `mrst_run` считает по
времени, `mrst_output` пишет `jsonencode`: время шагов, приемистость, отбор воды и нефти (м³/с), забойное давление
нагнетательной (Па), температуру ячейки добывающей (K) на каждом шаге и поля p, S_w, T в шагах `field_steps`
(ячейка (i, j) — элемент i + j·nx). Вывод Octave — `outputs/mrst/<имя>.log`.
`--mrst` гоняет прогоны теста параллельно (число ядер − 1), старты разнесены на 3 с: `startup.m` пишет настройки
MRST, и одновременные старты мешают друг другу. Готовый `outputs/mrst/<имя>.json` не пересчитывается — удалить его,
чтобы пересчитать; затем `save_reference` сжимает прогоны в `data/<тест>.npz` (суточные накопленные объемы,
забойное давление, температура на добывающей, поля в float32).

Вручную каждый файл запускается в MATLAB или Octave из каталога `tests/mrst_tests` без аргументов — тогда
считается постановка `start.py` по умолчанию (числа `constants.py` записаны в `mrst_start.m`), и функция
возвращает результат `r` (те же поля, что в JSON); графики не строятся, их рисует Python-тест:

```matlab
setenv('MRST_ROOT', 'C:\Program Files\GNU Octave\Octave-10.3.0\mrst-2024a')  % или run startup.m из каталога MRST
cd tests/mrst_tests
r = mrst_two_phase_implicit;     % 40x40, 2000 сут, ~15 мин в Octave
r = mrst_thermal;                % 20x20, 1000 сут
r = mrst_rate_control('../../outputs/mrst/incomp_n40_rate.case.json');  % постановка теста
```

В Octave `mrst_start` подменяет один метод MRST: в
`GeothermalGenericFacilityModel.getProductionWellTemperature` выражение `~ok.*map.perforationSum*Tperf./nc`
поэлементно умножает вектор на разреженную матрицу — MATLAB расширяет размерности, Octave для разреженных нет
(`product: nonconformant arguments`). Исправленная копия класса (то же значение) кладется во временный каталог
перед MRST в пути поиска (`octave_fix_geothermal`), установленный MRST не меняется.

Скорость (Ryzen 7 4700U): `ad-blackoil` — ~0.35 с на суточный шаг 20x20 и ~1.1 с на 75x75; `incomp` — ~0.12 с на
суточный шаг 75x75; `geothermal` — ~1.2 с на шаг 20x20. paraphin 75x75 — ~2–4 мин на 2000 сут.

## Чем модели отличаются

Это не ошибки ни одной из сторон, а разные соглашения — тесты закрепляют их отдельными проверками:

1. **Подвижность в нагнетательной.** paraphin берет полную подвижность воды k/μ_w (`well.calc_well_prod`), MRST —
   суммарную подвижность ячейки k·(k_rw/μ_w + k_ro/μ_o) (`computeWellContributionsNew.m`, `incompTPFA.m`; закачка по
   составу `setUpstreamMobility` в MRST отключена). При S = S_min она в μ_o/μ_w ≈ 14 раз меньше, и пока ячейка не
   промыта, MRST закачивает меньше (первые сутки: −21 % на 20x20, −9 % на 40x40) или, на заданном дебите, требует
   большего забойного. В варианте flooded расхождение уходит (+4 %).
2. **Подвижность на грани.** У paraphin и `incomp` суммарная подвижность — гармоническое среднее, доли фаз — против
   потока; у `ad-blackoil` фазовые подвижности целиком против потока. На этой задаче разница меньше 1 %.
3. **Время.** paraphin — явный перенос с шагом по Куранту (≤ 0.05 сут), `incomp` — давление раз в 0.25 сут,
   `ad-blackoil` и `geothermal` — неявный Эйлер с шагом 1 сут.
4. **Нагрев трением.** Энтальпия MRST h = u + p/ρ, то есть в его уравнении энергии есть −v·∇p — нагрев воды при
   течении. Вода, прошедшая весь перепад, нагревается на (Pw − Po)/(ρ_w c_w) ≈ 2.4 K; в paraphin этого слагаемого
   нет (`test_frictional_heating`). Подменить энтальпию в MRST нельзя одной функцией: p/ρ стоит и во flash
   (`computeFlashGeothermal`), и в источниках скважин.

## Результаты

Эталоны сняты 2026-10-08 (MRST 2024a, Octave 10.3.0; 13 прогонов — 24 мин на 6 процессах), все 25 проверок
проходят (`python -m pytest tests/mrst_tests`, ~9 мин). MRST − paraphin, двухфазная задача:

| прогон | L2 приемистости | L2 дебита нефти | закачка за 10 сут | Δнефти за 2000 сут | Δпрорыв, сут |
|---|---|---|---|---|---|
| `incomp` 20x20 / 40x40 / 75x75, native | 0.73 / 0.18 / 0.05 % | 2.31 / 1.00 / 0.54 % | −10.4 / −3.7 / −1.4 % | −0.11 / −0.01 / +0.02 % | +5 / +2 / +1 |
| `incomp` 20x20 / 40x40 / 75x75, flooded | 0.02 / 0.02 / 0.02 % | 0.15 / 0.24 / 0.32 % | 0.0 / +0.1 / +0.2 % | +0.01 / +0.01 / +0.03 % | 0 / +1 / 0 |
| `ad` 20x20 / 40x40 / 75x75, native | 0.25 / 0.11 / 0.21 % | 1.40 / 0.74 / 0.73 % | −8.9 / −2.6 / −0.7 % | −0.07 / −0.04 / −0.06 % | 0 / −2 / −2 |
| `ad` 20x20 / 40x40 / 75x75, flooded | 0.63 / 0.14 / 0.17 % | 1.46 / 1.14 / 0.88 % | +3.2 / +2.0 / +1.0 % | +0.06 / −0.01 / −0.05 % | −5 / −4 / −3 |
| `incomp` / `ad`, 40x40, закачка 100 м³/сут | — (задана) | 0.36 / 0.91 % | — | +0.02 / −0.06 % | 0 / −3 |
| `incomp` / `ad`, 40x40, неоднородная k | 0.09 / 0.74 % | 0.60 / 1.05 % | −1.9 / −0.9 % | +0.02 / +0.08 % | 0 / −3 |

- С IMPES MRST при промытой ячейке нагнетательной (одна и та же схема и одно соглашение) расхождение — на уровне
  шага по времени: 0.02 % по приемистости, ≤ 0.03 % по нефти, прорыв в тот же день.
- Без промывки отличаются только первые дни (соглашение о подвижности закачки), и разница убывает с сеткой: на
  75x75 ячейка нагнетательной меньше и промывается быстрее.
- С неявной схемой (подвижности против потока, неявный Эйлер с шагом 1 сут) — до 1.5 % по суточному дебиту нефти,
  ≤ 0.08 % по накопленной нефти, прорыв на 2–5 сут раньше.
- В режиме дебита забойное давление нагнетательной после 30 сут расходится на 0.12 % (`incomp`) и 0.17 % (`ad`).
- Поля: среднее |ΔS| ≤ 0.002, max |Δp| < 1 бар при перепаде 100 бар; на неоднородной k у `incomp` max |Δp| ≤ 0.08 бар.

Неизотермический тест (одна вода, 20 → 70 °C): приемистость расходится на 1.4 % (MRST закачал 313.5 тыс. м³ против
309.2 тыс.), температура на добывающей — не больше 0.7 K. Расхождение поля температуры — целиком нагрев трением в
MRST: ΔT положителен в 99 % ячеек и к 1000 сут в среднем равен (Pw − p)/(ρ_w c_w) (+1.29 K против 1.39 K на 20x20,
+1.37 против 1.375 K на 40x40); теплее вода — меньше ее вязкость, отсюда и лишние 1.4 % закачки.

Прорыв воды в двухфазной задаче — ~275 сут, КИН за 2000 сут — 48.3 % у всех. Поточечная разность обводненности
доходит до 0.1: это сдвиг почти вертикального фронта на сутки-двое, поэтому тесты проверяют среднюю разность и время
прорыва. В таблицах теплового теста столбцы нефти и обводненности не имеют смысла (нефти нет) и не проверяются.

## Что еще можно сравнить с MRST

| Что | Чем в MRST | Как |
|---|---|---|
| Теплопотери в кровлю и подошву (`heat_losses` 1 — Ловерье, 2 — Винсом–Вестервельд) | `geothermal`, 3D-сетка: пласт плюс непроницаемые слои кровли и подошвы с теплопроводностью | одна фаза, как `test_thermal`; полуаналитический обмен paraphin против явной теплопроводности в покрышках — проверка `E_ff` и `T_0` |
| Граничные условия Дирихле и Неймана по давлению, насыщенности, температуре | `pside`, `fluxside`, `addThermalBCProps` | одномерная прокачка (Nx×1) с ГУ на левой и правой границах; есть и аналитика Баклея–Леверетта |
| Уравнение состояния: flash, давление насыщения, тест устойчивости | `compositional`: `standaloneFlash`, `phaseStabilityTest`, `solveRachfordRiceVLE`, Пенг–Робинсон | без течения: смесь псевдокомпонентов `paraphin/thermo` (Tc, Pc, ω, kij) в обоих, сравнить фазовые доли, составы, P_b |
| Зависимость k от уменьшения пористости | `ad-micp` (закупорка кальцитом и биопленкой), `ad-eor` (`PolymerPermReduction`: снижение проницаемости адсорбированным полимером) | только замыкание k(m) или k(удержание) — `perm_model = 'power'`, `adsorption` с функцией повреждения; кинетика осаждения у них своя (бактерии, полимер в воде), постановки не совпадут |
| Сходимость по сетке и шагу | любой решатель | уже заложено: сетки 20/40/75 в двухфазных тестах; шаг `ad` можно уменьшить в `common.two_phase_cases` |

## Что сравнить нельзя

В MRST нет моделей:
- кристаллизации парафина, WAT, растворимости групп (multi-solid), скрытой теплоты кристаллизации;
- кольматации пучка капилляров: сужения каналов осадком (`Ur`) и блокирования горл (`Ub`), функции распределения
  пор `fi(r)`, сети пор и горл; глубинной фильтрации частиц;
- суффозии — выноса осевших частиц потоком;
- асфальтенов (Хиршберг, Nghiem, флокуляция, агрегация), адсорбции смол и асфальтенов из нефти;
- геля и течения Букингема–Райнера, вязкости суспензии кристаллов;
- двухфазного неизотермического течения нефть–вода: двухфазный режим `geothermal` — вода и пар одного компонента
  H₂O, без ОФП нефть–вода; поэтому температура сравнивается только на однофазной воде;
- локальной тепловой неравновесности (отдельная температура породы).

Эти механизмы проверяются по лабораторным опытам (`experiments/`) и аналитическим решениям
(`tests/test_kinetics_math.py`, `tests/test_heat_losses.py`), а сравнение с MRST закрепляет то, на чем они стоят:
поле давления, перенос насыщенности и тепла, скважины.
