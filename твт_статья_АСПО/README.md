# твт_статья_АСПО

Статья для журнала «Теплофизика высоких температур»: модель неизотермической фильтрации с детальным составом нефти,
кинетикой осаждения парафинов, смол и асфальтенов и теплообменом с вмещающими породами, ее проверка по керновым
опытам и влияние термических процессов и парафина на повреждение пласта. Объединяет прежнюю статью о теплопотерях
(`твт_статья/`, здесь не трогается: из нее взяты структура, полная запись уравнений, факторный план теплообмен x
парафин, сборка docx `твт_статья/make_docx.py` и стиль рисунков) со статьей об АСПО.

## Что где лежит

| Файл | Что это |
|---|---|
| `article.md` | Текст статьи, один на обе версии. Фрагменты между `<!-- полная -->` и `<!-- /полная -->` - только в полной версии. Числа и таблицы - подстановки `{{КЛЮЧ}}` из `results/numbers.json`, руками не набираются |
| `run_thermal.py` | Полевые варианты (элемент заводнения 50 x 50, 5 лет, пласт 55 C): по одному фактору от базового - температура закачки, теплообмен с кровлей и подошвой, нефть без парафина (с `hl0_nowax` - полный факторный план теплообмен x парафин), гель, удержание смол и асфальтенов, скрытая теплота, кинетика кристаллизации, давление в WAT, тепловое неравновесие. Параметры кинетики - из подборов по керну Li et al. (`experiments/params.json`). Результат - `results/thermal.json`, полные расчеты - `outputs/data/thermal_<вариант>__*` |
| `make_article.py` | Рисунки (`figures/aspo_f*.tif` 600 dpi, 256 оттенков серого, и `.png`; на картах полей - шкалы) и все числа текста (`results/numbers.json`, `metrics.md`) по `experiments/results/*.json`, `experiments/уравнение_состояния/results.json` и `results/thermal.json`. `aspo_f1`-`f6` - журнальная версия, `aspo_f7`-`f12` - только полная (`f12` - асфальтены Tabzar, в полной версии идет перед вязкостью `f11`) |
| `rules_checklist.md` | Чек-лист правил журнала с проверкой этой статьи |
| `article.docx` | Журнальная версия (17 страниц, 6 рисунков): подписи к рисункам с новой страницы после списка литературы, рисунки и в тексте, и после подписей (правила ТВТ, разд. II.1–3) |
| `article_full.docx` | **Объединенная статья** (около 35 страниц): обе статьи — о теплопотерях (`твт_статья/`) и об АСПО — и все сравнения с опытами. Сверх журнальной: подбор параметров по каждому опыту — что варьируется, пределы, метод, критерий (табл. 1); термодинамика и реология против независимых измерений — кривая выпадения, синтетические смеси da Silva et al. (в том числе твердо-твердый переход и твердый раствор UNIQUAC по Coutinho), сдвиг WAT с давлением и PVT по уравнению состояния, асфальтены (в том числе калибровка модели Нгхайема по кривой выпавших асфальтенов живой нефти Tabzar et al.), вязкость и гель (табл. 2, рис. 1–4); причины оставшихся расхождений по каждой серии керновых опытов; вариант на уравнении состояния; механизм на уровне капилляров и сопоставление с прежней однокомпонентной моделью. Подписи стоят под рисунками, рисунки, таблицы и источники перенумерованы по первому упоминанию (`твт_статья/make_docx.py::renumber`) |

## Пересобрать

```bash
python experiments/run_all.py --quick          # сравнения с опытами (если менялся код пакета)
python твт_статья_АСПО/run_thermal.py          # полевые варианты, ~6 ч на 8 ядрах; --metrics - только показатели
python experiments/уравнение_состояния/compare.py   # термодинамика против опытов (для полной версии; calibration.json
                                               # и состав/validation.json пишут experiments/calibrate.py и состав/validate.py)
python твт_статья_АСПО/make_article.py         # рисунки и числа
python docs/build_docx.py статья_АСПО статья_АСПО_полная   # article.docx и article_full.docx
```

Бюджет журнала - не более 17 страниц и 10 подрисунков: шесть рисунков, 2 + 1 + 2 + 1 + 2 + 2 подрисунка. Рисунки
полной версии нумеруются после журнальных, поэтому выброс блоков «полная» нумерацию не сбивает; нумерованных формул
в этих блоках нет. Объем в Word: журнальная версия 17 страниц, полная (объединенная) 35. В полной версии нумерованные формулы в блоках «полная» не заводятся (номера формул общие), а рисунки, таблицы и источники сборка перенумеровывает по первому упоминанию, поэтому новые можно добавлять с любыми номерами после журнальных.
