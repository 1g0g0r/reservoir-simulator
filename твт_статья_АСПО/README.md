# твт_статья_АСПО

Статья для журнала «Теплофизика высоких температур»: модель неизотермической фильтрации с детальным составом нефти,
кинетикой осаждения парафинов, смол и асфальтенов и теплообменом с вмещающими породами, ее проверка по керновым
опытам и влияние термических процессов и парафина на повреждение пласта. Объединяет прежнюю статью о теплопотерях
(`old_article.md`, папка `твт_статья/` удалена): из нее взяты структура, полная запись уравнений, факторный план
теплообмен x парафин, сборка docx (`make_docx.py`) и стиль рисунков; расчеты упрощенной модели лежат в
`однокомпонентная_модель/`.

## Что где лежит

| Файл | Что это |
|---|---|
| `article.md` | Текст статьи, один на обе версии. Фрагменты между `<!-- полная -->` и `<!-- /полная -->` - только в полной версии. Числа и таблицы - подстановки `{{КЛЮЧ}}` из `results/numbers.json`, руками не набираются |
| `run_thermal.py` | Полевые варианты (элемент заводнения 50 x 50, 5 лет, пласт 55 C): по одному фактору от базового - температура закачки, теплообмен с кровлей и подошвой, нефть без парафина (с `hl0_nowax` - полный факторный план теплообмен x парафин), гель, удержание смол и асфальтенов, скрытая теплота, кинетика кристаллизации, давление в WAT, тепловое неравновесие. Параметры кинетики - из подборов по керну Li et al. (`experiments/params.json`). Результат - `results/thermal.json`, полные расчеты - `outputs/data/thermal_<вариант>__*` |
| `make_article.py` | Рисунки (`figures/aspo_f*.tif` 600 dpi, 256 оттенков серого, и `.png`; на картах полей - шкалы) и все числа текста (`results/numbers.json`, `metrics.md`) по `experiments/results/*.json`, `experiments/уравнение_состояния/results.json` и `results/thermal.json`. `aspo_f1`-`f6` - журнальная версия, `aspo_f7`-`f12` - только полная (`f12` - асфальтены Tabzar, в полной версии идет перед вязкостью `f11`) |
| `old_article.md`, `old_article.docx` | Прежняя статья о теплопотерях через кровлю и подошву (однокомпонентная модель парафина, пять вариантов, сетка 75 x 75). Сохранена как есть, не пересобирается; ее числа (табл. 3, факторный план) зашиты в `OLD_FACTORIAL` в `make_article.py` |
| `make_docx.py` | Сборка docx по правилам ТВТ (стили, простые формулы текстом, подписи к рисункам, сквозная нумерация полной версии `renumber`); его импортируют `docs/build_docx.py` и `tests/test_tvt_docx.py` |
| `PravilaTVT.pdf` | Правила журнала для авторов |
| `материалы/` | `исправленные уравнения.docx` - постановка и вычислительная схема с правками автора (раздел модели обязан ему соответствовать); `full_review.pdf` - обзор по осаждению парафинов, асфальтенов и смол, на который ссылаются `paraphin/` и `docs/`; `rules_checklist.md` - полный чек-лист правил журнала |
| `однокомпонентная_модель/` | Расчеты прежней статьи: `run_cases.py` - пять вариантов (теплообмен x парафин, правит `paraphin/constants.py` на время прогона и восстанавливает в `finally`; перед запуском `Nx, Ny = 75, 75`), `make_figures.py` - рисунки и `metrics.md`, `run_grid_study.py` - необязательная проверка сходимости по сетке (`--nr` - по сетке радиусов пор) |
| `rules_checklist.md` | Проверка этой статьи по пунктам правил журнала (полный список пунктов - `материалы/rules_checklist.md`) |
| `article.docx` | Журнальная версия (17 страниц, 6 рисунков): подписи к рисункам с новой страницы после списка литературы, рисунки и в тексте, и после подписей (правила ТВТ, разд. II.1–3) |
| `article_full.docx` | **Объединенная статья** (около 35 страниц): обе статьи — о теплопотерях (`old_article.md`) и об АСПО — и все сравнения с опытами. Сверх журнальной: подбор параметров по каждому опыту — что варьируется, пределы, метод, критерий (табл. 1); термодинамика и реология против независимых измерений — кривая выпадения, синтетические смеси da Silva et al. (в том числе твердо-твердый переход и твердый раствор UNIQUAC по Coutinho), сдвиг WAT с давлением и PVT по уравнению состояния, асфальтены (в том числе калибровка модели Нгхайема по кривой выпавших асфальтенов живой нефти Tabzar et al.), вязкость и гель (табл. 2, рис. 1–4); причины оставшихся расхождений по каждой серии керновых опытов; вариант на уравнении состояния; механизм на уровне капилляров и сопоставление с упрощенной однокомпонентной моделью. Подписи стоят под рисунками, рисунки, таблицы и источники перенумерованы по первому упоминанию (`make_docx.py::renumber`) |

## Пересобрать

```bash
python experiments/run_all.py --quick          # сравнения с опытами (если менялся код пакета)
python твт_статья_АСПО/run_thermal.py          # полевые варианты, ~6 ч на 8 ядрах; --metrics - только показатели
python experiments/уравнение_состояния/compare.py   # термодинамика против опытов (для полной версии; calibration.json
                                               # и состав/validation.json пишут experiments/calibrate.py и состав/validate.py)
python твт_статья_АСПО/make_article.py         # рисунки и числа
python docs/build_docx.py статья_АСПО статья_АСПО_полная   # article.docx и article_full.docx
```

Бюджет журнала - не более 17 страниц и 10 подрисунков: шесть рисунков, 2 + 1 + 2 + 1 + 2 + 2 подрисунка. Рисунки
полной версии нумеруются после журнальных, поэтому выброс блоков «полная» нумерацию не сбивает; нумерованных формул
в этих блоках нет. Объем в Word: журнальная версия 17 страниц, полная (объединенная) 35. В полной версии нумерованные формулы в блоках «полная» не заводятся (номера формул общие), а рисунки, таблицы и источники сборка перенумеровывает по первому упоминанию, поэтому новые можно добавлять с любыми номерами после журнальных.

Упрощенная модель (только при необходимости, результат уже учтен в `OLD_FACTORIAL`):

```bash
python твт_статья_АСПО/однокомпонентная_модель/run_cases.py     # пять вариантов; можно номера: run_cases.py 1 4
python твт_статья_АСПО/однокомпонентная_модель/make_figures.py  # рисунки и metrics.md прежней статьи
```
