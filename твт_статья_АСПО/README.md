# твт_статья_АСПО

Статья для журнала «Теплофизика высоких температур»: модель неизотермической фильтрации с детальным составом нефти
и кинетикой осаждения парафинов, смол и асфальтенов, ее проверка по керновым опытам и влияние термических
процессов на повреждение пласта. Прежняя статья о теплопотерях лежит в `твт_статья/` и здесь не трогается; из нее
берутся сборка docx (`твт_статья/make_docx.py`) и стиль рисунков.

## Что где лежит

| Файл | Что это |
|---|---|
| `article.md` | Текст статьи. Числа и таблицы в нем - подстановки `{{КЛЮЧ}}` из `results/numbers.json`, руками не набираются |
| `run_thermal.py` | Полевые варианты (элемент заводнения 50 x 50, 5 лет): по одному фактору от базового - температура закачки, теплообмен с кровлей и подошвой, скрытая теплота, кинетика кристаллизации, давление в WAT, тепловое неравновесие, удержание. Параметры кинетики - из подборов по керну Li et al. (`experiments/params.json`). Результат - `results/thermal.json`, полные расчеты - `outputs/data/thermal_*` |
| `make_article.py` | Рисунки (`figures/aspo_f*.tif` 600 dpi, 256 оттенков серого, и `.png`) и все числа текста (`results/numbers.json`, `metrics.md`) по `experiments/results/*.json` и `results/thermal.json` |
| `rules_checklist.md` | Чек-лист правил журнала с проверкой этой статьи |
| `article.docx` | Собранная статья |

## Пересобрать

```bash
python experiments/run_all.py --quick          # сравнения с опытами (если менялся код пакета)
python твт_статья_АСПО/run_thermal.py          # полевые варианты, ~4 ч на 4 ядрах; --metrics - только показатели
python твт_статья_АСПО/make_article.py         # рисунки и числа
python docs/build_docx.py статья_АСПО          # article.docx
```

Бюджет журнала - не более 17 страниц и 10 подрисунков: шесть рисунков, 2 + 1 + 2 + 1 + 2 + 2 подрисунка.
