# Чем заменить идеальный раствор с эффективными параметрами

*Ответ на вопрос о модели парафина, которая описывала бы любой опыт проекта (07.10.2026). Числа — из
`твт_статья_АСПО/metrics.md` и `experiments/уравнение_состояния/results.json`.*

## Что означают эффективные параметры настоящей модели

Настоящая модель — идеальный раствор с несколькими чистыми твердыми фазами, четыре группы н-алканов. По кривой
выпадения нефти Жетыбая (ДСК, Li et al., 2024) подобраны три числа:

1. **Наклон распределения н-алканов s.** Состав парафина нефти задан законом z_n ∝ e^(−sn), а не измерен
   хроматографически. Для синтетических смесей этот параметр не нужен.
2. **Сдвиг температур плавления, +52.4 K** ко всем Tm по Вону. Для чистых н-алканов Вон и так точен: для C24 он
   дает 50.6 °C при опытных 50.9 °C.
3. **Общая теплота растворения ΔH_eff = 41.9 кДж/моль** для всех групп. По калориметрии теплота больше и растет
   с длиной цепи: для C24 по Вону 65.5 кДж/моль.

Сдвиг и теплота компенсируют друг друга. Если взять только сдвиг, WDT синтетических смесей будет 61–69 °C. Если
только заниженную теплоту, то от −20 до −10 °C. Вместе они попадают в кривую нефти, но уже не попадают в смеси.

Эта пара поглощает то, чего нет в самой модели, но что есть в нефти:

- неизмеренный хвост распределения н-алканов;
- изо- и циклоалканы с меньшими температурами и теплотами плавления;
- разницу между температурой появления кристаллов при охлаждении (ДСК) и температурой их исчезновения при
  нагреве (модель);
- неидеальность раствора;
- конкретное разбиение на группы.

В смесях чистых н-алканов в декане ничего этого нет. Поэтому поправки, подобранные для нефти, компенсируют
несуществующие ошибки и уводят WDT вниз: на смесях da Silva et al. (2017) отклонение WDT от опыта −24.2…−13.4 °C,
доли твердого — 3.1–9.3 % масс. (рис. 9б, 9в статьи, кривая 1). Расчет по Вону без подбора дает там −11.3 °C в
среднем, то есть эффективные параметры на смеси переносятся хуже, чем их отсутствие.

## Более детальная модель

В коде (`paraphin/thermo`) она уже почти вся есть:

1. **Жидкость** — уравнение Пенга—Робинсона. Нужно для живой нефти и влияния давления; для дегазированной нефти
   почти не отличается от идеального раствора (поправка 1–2 °C).
2. **Твердая фаза** — твердый раствор UNIQUAC Coutinho вместо нескольких чистых твердых фаз
   (`solids.UniquacSolidWax`).
3. **Свойства плавления** — по Coutinho, с твердо-твердым переходом (`characterization.coutinho_nalkane`), а не по
   Вону с подобранным сдвигом Tm и общей теплотой.
4. **Скачок объема при кристаллизации** — физический, из плотностей. Он задает зависимость WAT от давления.
5. **Кинетика кристаллизации** (`K_CRYST`) — связывает равновесную температуру исчезновения кристаллов с
   температурой их появления, которую мерят при охлаждении ДСК и реометр. Проверка по WAT раствора Sandyga при
   разных скоростях охлаждения (Struchkov, Rogachev, 2017; `experiments/sandyga2020.wat_rate`) это подтвердила:
   отклонение 0.21 °C при пороге видимости 0.16 % кристаллов.
6. **Асфальтены** — модель Нгхайема, откалиброванная по кривой количества выпавших асфальтенов.

На синтетических смесях эта связка без подбора дает WDT с точностью −0.4…+0.8 °C — уровень лучшей опубликованной
модели.

## Почему она не описывает любой опыт

Мешает не модель, а нехватка данных о составе. Детальной модели нужен состав н-алканов по высокотемпературной
хроматографии — каждый от C10 до C60+. Нужна и доля н-алканов в «парафине» по ДСК: остальное — изо- и
циклоалканы.

| Опыт | Что известно о составе | Что даст детальная модель |
|---|---|---|
| Синтетические смеси da Silva | все компоненты | точный прогноз без подбора (уже есть) |
| Li, нефть Жетыбая | только кривая ДСК, 24.9 % парафина | без хроматограммы — подбор. UNIQUAC даже с подобранным распределением дает WAT 62 °C против 45.6 °C и отклонение 3.2 % против 0.39 % у эффективной модели |
| Sandyga, Struchkov | парафин Т-1 в керосине (C20–C40) | хроматограмму технического парафина можно найти или снять, тогда модель применима |
| Sutton & Roberts, Maloney | только точка помутнения и количество твердого | детальная модель не определяется, остаются эффективные параметры |
| He et al. | только пары k(m) | термодинамика не нужна |

На нефти Жетыбая разница 62 против 45.6 °C слишком велика, чтобы ее объяснило одно запаздывание кристаллизации при
скорости ДСК (обычно несколько градусов). Скорее всего, тяжелый хвост н-алканов в нефти меньше, чем дает
экспонента. Кроме того, часть «парафина» ДСК — не н-алканы.

Поэтому при отсутствии хроматограммы честнее подбирать не свойства плавления, а то, чего не хватает в составе:

- распределение н-алканов;
- долю н-алканов в парафине по ДСК.

Остальные изо- и циклоалканы идут в растворитель или в отдельный легкоплавкий псевдокомпонент. Свойства плавления
при этом остаются физическими (Coutinho), а кинетика объясняет разницу между появлением и исчезновением
кристаллов. Тогда подобранные параметры имеют смысл состава, а модель переносится на смеси.

## Следующие шаги

1. **Проверка на нефти Жетыбая** (`experiments/уравнение_состояния/compare.py`): UNIQUAC + свойства Coutinho +
   подбор доли н-алканов в парафине ДСК и распределения, с запаздыванием по `K_CRYST` при скорости ДСК. Покажет,
   может ли физическая модель с подбором состава догнать эффективную (0.39 % масс.). Дешево: около 10 минут расчета.
2. **Подключение UNIQUAC к расчету пласта.** Заметно сложнее: при твердом растворе насыщение каждой группы
   зависит от состава твердой фазы, и одномерные таблицы `LNXSAT[k, T, P]`, которые читают ядра
   (`thermo/tables.py`), не годятся. Нужна новая схема таблиц или расчет равновесия в ядре.
