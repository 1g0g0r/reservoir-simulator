# docs — описания моделей и физики процессов

Здесь лежат тексты о том, **что и почему** считает симулятор `paraphin`: постановка, замыкающие соотношения,
источники формул, обоснование параметров. Сравнения с опытами, подбор параметров по ним и отчеты о
расхождениях — в `experiments/` (см. `experiments/README.md`). Устройство кода и правила работы с ним —
в `CLAUDE.md` в корне.

## Рисунки

`figures/fig*.png` строит `python docs/make_model_figures.py`. Скрипт использует калибровку из
`experiments/results/calibration.json` (`python experiments/calibrate.py`) и демонстрационный расчет
(`python demo_composition.py`). `figures/kin*.png` к `кинетика_осаждения.md` — аналитические проверки моделей
кинетики, строит `python docs/make_kinetics_figures.py` (секунды, прогонов не требует).

## Сборка docx

`python docs/build_docx.py [имя ...]` собирает документы из `DOCS` в `build_docx.py`, а без аргументов — все.
Формулы TeX pandoc переводит в формулы Word (OMML). Стили общие со статьей (`твт_статья_АСПО/make_docx.py`).
pandoc берется из `pypandoc_binary`. Этот же скрипт собирает отчеты в `experiments/`.
