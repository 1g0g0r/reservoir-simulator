# 0. СТРУКТУРА МЕТОДА

Схема — IMPES (Implicit Pressure, Explicit Saturation) на регулярной прямоугольной сетке, метод конечных объемов (МКО). Давление находится неявно: одна симметричная положительно определенная СЛАУ на шаг. Насыщенность, состав нефти, температура и поровая структура — явно по ячейкам, с разностью против потока. Шаг по времени адаптивный (число Куранта). Нелинейных внешних итераций нет, подшагов нет: один шаг — одно решение СЛАУ и один проход по ячейкам.

Две части расчета разнесены по времени:

- **при импорте пакета** — тяжелая термодинамика: характеризация состава, калибровки, таблицы равновесия на уравнении состояния Пенга–Робинсона (PR) по сетке температура × давление (разд. 11); результат кешируется на диск;
- **на каждом шаге** — только дешевые ядра numba: замкнутые формулы, жадный перебор, билинейная интерполяция таблицы (разд. 10, 11.9).

Уравнение состояния, flash и тест устойчивости в шаге по времени не вызываются.

Схемы дискретизации (пространство, время, расщепление), методы решения подзадач и псевдокод шага собраны в разд. 19.

# 1. ДОПУЩЕНИЯ ЧИСЛЕННОЙ СХЕМЫ

1. **Коэффициенты давления явные.** Подвижности $\lambda_\alpha$ и вязкости берутся со слоя $n$ (вязкости посчитаны в конце прошлого шага по температуре нового слоя). Неявно решается только зависимость давления от давления.
2. **Схема против потока первого порядка** для насыщенности, состава и температуры: фронты размазываются на порядок ячейки (численная диффузия), монотонность сохраняется.
3. **Условие устойчивости — Курант**, и только оно. Осаждение шаг не ограничивает: его сток зажат подводом взвеси внутри ядра (разд. 13).
4. **Насыщенность не зажимается** в $[S_{min}, S_{max}]$: функции ОФП $f_w$, $f_o$ вне диапазона выходят на 0 и 1, поток монотонен, схема с шагом по Куранту из диапазона не выходит.
5. **Один слой на поле.** Каждое поле хранится как $X$ (слой $n$) и $new\_X$ (слой $n+1$); уравнение обязано записать $new\_X$ в каждой ячейке каждого шага. Слой $n-1$ хранится только у температуры (метод Винсома–Вестервельда).
6. **Последний шаг не подрезается** до `Time_end`. Останов также по обводненности добывающей скважины $\eta \ge$ `max_eta`.
7. **Прогревочный шаг.** `Solver.start` один раз вызывает `upd_time_step(0.0)`: это компиляция numba, но шаг считается реально (время расчета при этом не растет, потери тепла при $t \le 0$ равны нулю).
8. **Флаги — константы модуля.** Numba вшивает значения `constants.py` и выбрасывает выключенные ветки при компиляции. Расчет с другой комбинацией флагов — только в копии пакета (`tests/_patched_copy.make_copy`).

# 2. СЕТКА, РАСКЛАДКА ДАННЫХ, ГРАНИЧНЫЕ УСЛОВИЯ

## 2.1. Геометрия ячейки

Сетка $N_x \times N_y$ с шагами $h_x$, $h_y$, толщина пласта $h$ (`constants.py`). Четыре грани ячейки обходятся по таблицам `FVM_utils.py`: сдвиги индексов `DI = [1, -1, 0, 0]`, `DJ = [0, 0, 1, -1]`, расстояния между центрами `HIJ = [hx, hx, hy, hy]`, площади `AREA = [hy·h, hy·h, hx·h, hx·h]`. Эта единственная копия геометрии используется и для матрицы давления, и для перетоков.

## 2.2. Раскладка вектора давления

Ячейка $(i, j)$ в векторе давления — позиция `P0 + i + j*PX` (`layout.py`), где $PX = N_x + 2$, $P0 = PX + 1$. Вокруг сетки лежит рамка фиктивных ячеек с нулями — как уровни многосеточного решателя; благодаря ей внутренние циклы PCG и сглаживания не проверяют границы. После решения давление раскладывается в двумерное поле циклом `p[i, j] = p_vec[P0 + i + j*PX]` (быстрый индекс — $i$). Перепутать оси здесь легко, но на симметричной постановке это не видно; инвариант закреплен в `tests/test_pressure_orientation.py`.

## 2.3. Граничные условия

Массив `boundary_conditions[граница, поле]` со структурным dtype `BC` (`type`, `value`); границы — Left/Right (индекс $j$ за сеткой), Top/Bottom (индекс $i$ за сеткой), поля — давление, насыщенность, температура, парафин. `apply_bc` возвращает значение поля в **фиктивной ячейке** за границей:

- Дирихле — заданное значение $F_b$ на грани;
- Нейман с градиентом $g$ — $F_c + g\,h_f/2$ (при $g = 0$, а это умолчание, — непроницаемая теплоизолированная граница).

Для грани на границе подвижность считается по свойствам самой ячейки ($k$, $\mu$ ячейки), но с полем из ГУ ($S_{gh}$ из ГУ). Проводимость грани — гармоническое среднее подвижностей ячейки и фиктивной ячейки, расстояние $h_f/2$:

$$T_b = \frac{2\lambda_c\lambda_{gh}}{\lambda_c + \lambda_{gh}}\,\frac{A_f}{h_f/2}. \qquad (2.1)$$

Для Дирихле по давлению $T_b$ уходит на диагональ, $T_b\,p_b$ — в правую часть; для Неймана поток $g A_f \lambda_{face}$ не зависит от давления и входит только в правую часть. Состав втекающей нефти: при Дирихле по `DataField.Paraffin` суммарная доля парафина задана ГУ (группы масштабируются по начальным пропорциям, `Solver.bc_Wc`; при `wax_kinetics` взвесь берется равновесной при $T$ границы), равновесие границы — `single_split` или `sle_hl_boundary`; без ГУ состав втекающей нефти равен составу самой ячейки.

# 3. ИНИЦИАЛИЗАЦИЯ

`Solver.initialize` (вызывается из `start`) делает по порядку:

1. **Проверки скважин.** Добывающая скважина ровно одна (ее индекс — `_producer`); хотя бы одна скважина на заданном забойном давлении — иначе задача чисто нейманова и матрица вырождена.
2. **Интегралы пучка** $\int r^2\varphi_0\,dr$, $\int r^4\varphi_0\,dr$ (`_calc_integrals`). Функция $\varphi_0$ кусочно-линейна: на отрезке $[r_{i-1}, r_i]$ имеем $\varphi = a + b r$, интеграл берется точно: $\int r^2\varphi = a\Delta r^3/3 + b\Delta r^4/4$ (для $r^4$ — $5$ и $6$). Они нормируют пористость и проницаемость пучка.
3. **Начальный состав** `_init_composition`: `sle_split` при `init_T`, `init_p` дает растворенные/взвешенные доли групп и носитель теплоты $H_l$. С асфальтенами начальные флокулы $= \max(a_{tot} - w_{max}, 0)$ — мгновенное равновесие. Если оно ненулевое, печатается предупреждение (нефть изначально не в равновесии). При `wax_kinetics` взвесь берется равновесной, при `asph_aggregation` — число первичных частиц.
4. **Начальное удержание** `_init_retention` — только при `adsorption` и `ads_init_equilibrium`: равновесие Ленгмюра $G = G_{max} K c/(1 + K c)$ при `init_T` по пластовой нефти, $\sigma_0 = (G_a + G_r)/\rho_{ad}$; повреждение проницаемости считается от него (`kx['sig0']`). Ошибка, если доля повреждения достигает 1.
5. **`preprocess_wells`** кладет на скважину индекс правой части `idx_rhs = P0 + i + j*PX`.
6. **Таблица $dF/dS$** для шага по времени (разд. 15.2).

# 4. ПОРЯДОК ОДНОГО ШАГА

`Solver.upd_time_step(t)` (`solver.py`) собирает шаг прямо в методе, а не в общей njit-обертке: так стадии меряет `bench.py` и подменяют опыты. Порядок:

1. **Подвижности** слоя $n$ (`calc_mobility`; с `wettability` — `calc_mobility_w`): $\lambda_o$, $\lambda_w$ и эффективная теплопроводность $\lambda_h$. Все, что у ячейки одно на четыре грани, считается здесь один раз.
2. **Давление** `calc_pressure`: сборка матрицы в три диагонали, учет скважин, проекция начального приближения, PCG с многосеточным предобуславливателем, раскладка в поле $p$ (разд. 5).
3. **Дебиты скважин** `_update_wells_data`: по новому давлению и теми же коэффициентами продуктивности $J$, что стояли в матрице; обводненность, накопленные дебиты, КИН (разд. 6).
4. **Источники скважин** `_wells_loop`: буферы `src_S`, `src_T`, `src_Qo` в тех же единицах, что перетоки через грани (м³/с, Вт); их ячейки перезаписываются каждый шаг.
5. **Уравнения по ячейкам** `_equations_loop` — три прохода (разд. 4.1).
6. **Шаг для следующей итерации** `_calc_dt` (разд. 15).
7. Проверка конечности давления (`isfinite(p.sum())`, иначе `FloatingPointError`).
8. **Обмен слоев** `_swap_time_steps`, затем `_swap_refs` (разд. 16).
9. **Сохранение**, если $t \ge i_{img}\,\Delta t_{sol}$, либо последний шаг, либо останов по обводненности.

Порядок значим: перенос компонентов делит на $mS_o$ **нового** слоя и использует стоки нового слоя; температуре нужны $S$, $m$, $w_p$ нового слоя. Поэтому внутри ячейки жестко: насыщенность → кольматация (если она в проходе 1/2) → компоненты → температура.

## 4.1. Три прохода `_equations_loop`

Все проходы — `prange` по строкам или по списку ячеек; ячейки независимы. Все перетоки берутся с текущего слоя и нового давления.

**Проход 1 — перетоки и (при кинетике) осаждение.** В каждой ячейке: скорость в капилляре и $|\nabla p|$ (`calc_Um_r2`, центральные разности внутри, односторонние на границах), потоки через четыре грани и оттоки (`flows_in_cells`, разд. 7). При `deposition_kinetics` и разрешенной кольматации здесь же вызывается кинетическое ядро (`calc_deposition` или `calc_filtration`), ему передается запас для ограничителя: $out_o = q_{o,out} + \max(-src_{Q_o}, 0)$ (отток нефти через грани и добывающую скважину). Без кинетики, но с асфальтенами, считается скорость сужения флокулами `calc_velocity_asph` (запишется в $new\_kx.ua$ и будет прочитана на следующем шаге).

**Проход 2 — кольматация пучка (только без кинетики).** Список активных ячеек: $w_{ps} > $ `min_Wps_bound` либо сужение флокулами ($ua < 0$). Все они, как правило, у нагнетательной скважины, поэтому цикл по строкам дал бы один-два потока; ячейки списка раздаются кускам по кругу, скретч куска — `rows[c]`. В ячейке: `calc_velocities_h` → `calc_qp_m_k_fi` (разд. 13.1–13.3).

**Проход 3 — гидродинамика, перенос, температура.** В ячейке по порядку:

1. неактивные ячейки: $new\_q_{p1} = new\_q_{p2} = 0$, $new\_m = m$, $new\_k = k$ (ядро не вызывалось);
2. добавление скважин: `cells_S_eq += src_S`, `cells_T_eq += src_T`;
3. насыщенность (разд. 7.2);
4. перенос компонентов `components_equation` (разд. 9) вместе с равновесием и асфальтенами (разд. 10–12);
5. температура: `temperature_equation` или LTNE (разд. 8);
6. вязкость воды $\mu_w(new\_T)$ и, если нет геля и Баруса, вязкость нефти $\mu_o(new\_T, new\_w_{ps})$ (с гелем или Барусом — в `_swap_time_steps`);
7. три условия Куранта (разд. 15).

## 4.2. Параллелизм и ловушки

`parallel=True` стоит там, где ячейки независимы: `_equations_loop`, `_swap_time_steps`, сборка матрицы, `calc_mobility`, ядра уровней многосеточного решателя (мелкие уровни — последовательно), проекция. Три ловушки, влияющие на корректность (подробно — `CLAUDE.md`):

- кортеж с переприсвоением индекса внутри `prange` приводит индекс к `float64` — поэтому свойства соседа читаются внутри каждой ветки;
- скретч прогонки по радиусам — запись `rows[i]` массива `Solver.rows` со структурным dtype `layout.ROWS`; общий буфер дал бы гонку и недетерминированный счет (проверка — два прогона побитово совпадают);
- ключ дискового кеша numba не содержит флагов компиляции — последовательная и параллельная версии одной функции живут под разными именами (`mg_solver._serial`).

# 5. ДАВЛЕНИЕ

## 5.1. Дискретизация

Сумма балансов воды и нефтяной фазы целиком (несжимаемые фазы) не содержит производных по времени. В ячейке $c$:

$$\sum_{f}T_f\,(p_f - p_c) + q_c = 0,\qquad T_f = \frac{2\lambda_c\lambda_f}{\lambda_c + \lambda_f}\,\frac{A_f}{h_f},\qquad \lambda = \lambda_o + \lambda_w, \qquad (5.1)$$

гармоническое среднее $mid(x, y) = 2xy/(x+y)$ (0 при нулевой сумме). Матрица $M = -A$ хранится тремя диагоналями (шаблон пятиточечный):

- `diag[c]` — сумма проводимостей четырех граней (плюс $J_t$ у скважины на забойном давлении, плюс $T_b$ у границы Дирихле);
- `ex[c]` $= -T$ к соседу $i+1$, `ey[c]` $= -T$ к соседу $j+1$; связи влево и вниз читаются как `ex[f-1]`, `ey[f-PX]`. Каждая ячейка пишет только свои три значения, поэтому сборка параллельна без согласования порядка записи; `ex = 0` на $i = N_x - 1$, `ey = 0` на $j = N_y - 1$.

Знаки: $M p = q$ при $q > 0$ — закачка, $q < 0$ — отбор. $M$ симметрична, диагонально доминантна, неприводима; скважины на забойном давлении и Дирихле дают строгое доминирование, значит $M$ положительно определена и метод сопряженных градиентов применим. В правую часть входят **только** дебиты и вклад Дирихле: прежний источник с производной пористости убран, потому что он возникал из сложения баланса воды с балансом отдельного компонента и давал невязку дебитов (`tests/test_mass_balance.py`).

## 5.2. Решатель: PCG с многосеточным предобуславливателем

(Полное описание — `docs/решатель_давления.md`.)

**Уровни.** Грубые уровни — агрегация $2\times 2$ по Галеркину с кусочно-постоянным продолжением $P$: $A_c = P^T A P$. Каждый уровень снова пятиточечный и хранится тремя диагоналями в плоских массивах (`Solver.mg_buf`). Диагональ блока — сумма диагоналей четырех ячеек плюс удвоенные внутренние связи; связь соседних блоков — сумма связей через общую грань. Огрубление идет, пока $n_x n_y > 64$ и обе стороны $> 2$ (для $100 \times 100$ — пять уровней, до $7 \times 7$). Одномерный керн ($N_x = 1$ или 2) огрублять нечего: уровень один, решает его ленточный Холецкий.

**V-цикл** (`mg_vcycle`) — симметричный, чтобы годиться предобуславливателем для CG:

1. спуск: красно-черный Гаусс–Зейдель (красные ячейки — четное $i + j$); красный полушаг при нулевом начальном $x$ — просто $x = b/D$;
2. невязка считается только в красных ячейках блока ($(0,0)$ и $(1,1)$ блока $2\times 2$), так как невязка черных нулевая, и сразу сворачивается в правую часть грубого уровня;
3. на самом грубом уровне (≤ 64 ячеек) — ленточный Холецкий (полуширина ленты — $n_x$ уровня); неположительный ведущий элемент — ошибка «матрица давления вырождена»;
4. подъем: черный полушаг с поправкой «на лету» ($x_r + s\,x_c$), затем красный; порядок полушагов зеркален порядку спуска;
5. множитель грубой поправки $s$ = `p_mg_scale` (1.7): агрегация без сглаживания продолжения недооценивает поправку.

**Пересборка грубых уровней** по правилу цены: операторы пересобираются за $O(N)$, а матрица меняется за шаг на ~0.2 %. Состояние — `Solver.p_state`: возраст `age`, суммарные итерации `cost`; пересборка на следующем шаге, если текущее число итераций $it$ удовлетворяет $it\cdot age > $ `p_mg_setup_ratio` $+ \sum it$ (цена пересборки ~0.3 итерации). Мелкий уровень всегда свежий — это сама матрица. Если PCG на устаревших уровнях не сошелся — немедленная пересборка и повтор; если снова не сошелся — `ValueError`.

**PCG** (`pcg_mg`): $r = b - Mx$; остановка при $\|r\| \le$ `p_pcg_rtol`$\cdot\|b\|$ (1e-10). Итерация — три слитых параллельных прохода: `_direction` ($p = z + \beta p$, $q = Mz + \beta q$, $p\cdot q$ — используется $M(z+\beta p) = Mz + \beta q$, отдельного $Mp$ нет), `_update` ($x$, $r$, $\|r\|^2$) и скалярное произведение. Не сошелся за `p_mg_maxit` (200) — ошибка. Невязка и предобусловленная невязка живут в строках `_B` и `_X` мелкого уровня буфера: копий между PCG и V-циклом нет. Параллельные версии ядер — от `p_mg_par_min` ячеек уровня (4000).

**Начальное приближение** — проекция на разности прошлых решений (Fischer, 1998; `utils/math_utils/guess.py`): $x_0 = x_1 + \sum_a c_a d_a$, $d_a = x_a - x_{a+1}$, из кольца `Solver.p_hist` из `p_guess_m + 1` решений. Коэффициенты минимизируют ошибку в энергетической норме: $(D^T M D)c = D^T(b - Mx_1)$. Грам считается по самим разностям, $M d_a$, а не разностью произведений $M x_a - M x_{a+1}$: Грам обусловлен на $10^{10}$–$10^{11}$, и разность произведений теряет нужные знаки. Масштабирование диагональю, Холецкий; направления с ведущим элементом $\le 10^{-14}$ отбрасываются (на старте проекция сводится к прошлому решению). Итераций — 0.5–0.8 на шаг вместо 1.7 у квадратичной экстраполяции.

Следствие остановки по `p_pcg_rtol`: два расчета с разным порядком сложения расходятся на ~1e-10 по давлению и сильнее по малым разностям (взвесь — ~4e-9).

# 6. СКВАЖИНЫ

Связь забоя с ячейкой — формула Писмана (`utils/well.py`). Скважина — запись структурного массива `Solver.well_data[n_wells]` (dtype `WELL`), в ядра идет массив, в Python — тот же буфер как `np.recarray`.

**Коэффициенты продуктивности** (`calc_well_prod`) — единственное место с этой формулой. Множитель $\mathrm{pm} = 2\pi h/\ln(r_e/r_w)\cdot mult$, $r_e = 0.14\sqrt{h_x^2 + h_y^2}$ (`constants.py`):

$$J_w^{inj} = \mathrm{pm}\,\frac{k}{\mu_w},\quad J_o^{inj} = 0;\qquad J_\alpha^{prod} = \mathrm{pm}\,\frac{k\,f_\alpha(S)}{\mu_\alpha}, \quad J_t = J_o + J_w \qquad (6.1)$$

(при `wettability` — через смешанные подвижности). Проницаемость берется текущая, $k$ ячейки: кольматация призабойной зоны — основной эффект задачи. Коэффициенты считаются по слою $n$ **до** решения СЛАУ, кладутся в запись скважины, и после решения те же коэффициенты умножаются на перепад с новым давлением. Дебит нигде не считается отдельной формулой — иначе матрица и дебиты молча разошлись бы.

**Два режима** (`add_well` требует ровно один аргумент):

- **заданное забойное давление** `p`: в матрице $diag \mathrel{+}= J_t$, $rhs \mathrel{+}= J_t\,p_w$; после решения $\Delta p = p_w - p_c$, $q_\alpha = J_\alpha\Delta p$;
- **заданный дебит** `q` (положительное число для любой скважины; знак внутри — $q>0$ закачка, у добывающей меняется в `add_well`): в матрице только $rhs \mathrel{+}= q_t$, диагональ не меняется — уровень давления он не закрепляет; после решения $\Delta p = q_t/J_t$ (0 при $J_t = 0$), $p_w = p_c + \Delta p$ — забойное давление вычисляется каждый шаг; по фазам дебит делится в долях подвижности, как источник вошел в матрицу.

Обводненность добывающей — функция Баклея–Леверетта насыщенности ячейки, $\eta = f_w/(f_w + f_o\mu_w/\mu_o)$; у нагнетательной $\eta = 1$. КИН: $-\sum Q_o/$`geological_reserves`. Критерий останова и условие сохранения читают $\eta$ единственной добывающей скважины. Проверка баланса закачки и отбора — на уровне `p_pcg_rtol` (~1e-11), а не схемы (`test_mass_balance`).

# 7. ПЕРЕТОКИ И НАСЫЩЕННОСТЬ

## 7.1. Потоки через грани (`flows_in_cells`)

Поток суммарного объема через грань (положителен при притоке):

$$F_f = \frac{p_n - p_c}{h_f}\,A_f\,\mathrm{mid}(\lambda_c, \lambda_n). \qquad (7.1)$$

Направление выбирает давление: $p_c \ge p_n$ — выше по потоку своя ячейка (отток), иначе сосед. В ячейке выше по потоку берутся доли фаз $f_{w,up} = \lambda_{w,up}/(\lambda_{o,up} + \lambda_{w,up})$, $f_{o,up}$ (0 при нулевой сумме), температура и объемная энтальпия нефти, **одной веткой**. Фазовые потоки: $q_w = f_{w,up}F_f$, $q_o = f_{o,up}F_f$. Гармоническое среднее для долей и температуры не годится: нулевая доля обнулила бы поток. Выбор апвинда по знаку потока делает конвективный член консервативным и на оттоке.

Накапливаются: `cells_S_eq` $= \sum q_w$; тепловой приток $\sum[\mathrm{mid}(\lambda_{h,c}, \lambda_{h,n})A_f(T_n - T_c)/h_f + c_w\rho_w T_{up}q_w + h_{oil,up}\,q_o]$ (кондукция плюс конвекция; $h_{oil} = c_o T + \Lambda\,H_l$); `cells_Q_out` $= \sum(-F_f)$ по граням с оттоком; потоки нефти $q_o$ — в `Fo[i, j, грань]` при нескольких переносимых компонентах, либо сразу приток единственного компонента $\sum q_o W_{sum,up}$ в `cells_W_eq`. Функция возвращает также оттоки для условий Куранта: отток нефти $f_{o,c}Q_{out}$ и тепловой отток $(c_w\rho_wf_{w,c} + c_{oil}f_{o,c})Q_{out} + \sum\lambda_{heat}$. Перетоки — отдельным проходом: их вызов внутри большого цикла раздувал тело и стоил +40 % времени.

**Граница:** свойства соседа берутся из самой ячейки, меняется только поле (p, S, T из ГУ); состав втекающей нефти — разд. 2.3.

**Joule–Thomson** (`joule_thomson`): к тепловому притоку грани добавляется работа сил давления за вычетом теплового расширения $\mathrm{share}\,(p_n - p_c)\,[(1-\beta_wT_K)q_w + (1-\beta_oT_K)q_o]$; $\mathrm{share} = 0.5$ для внутренней грани, 1 для границы. Слагаемое неотрицательно.

## 7.2. Насыщенность

Явная схема в консервативной форме (`Saturation.py`): $m^{n+1}S^{n+1} = m^nS^n + \Delta t\,Q_w/V$, где $Q_w = \sum q_w + src_S$:

$$S^{n+1} = S^n + \frac{-S^n(m^{n+1} - m^n) + \Delta t\,Q_w/V}{m^{n+1}}. \qquad (7.2)$$

Деление на пористость нового слоя; зажима нет (допущение 4).

# 8. ТЕМПЕРАТУРА

## 8.1. Баланс энергии

Уравнение энергии решается явно, консервативно по произведению $\psi T$:

$$\psi^{n+1}T^{n+1}V = \psi^nT^nV + \Delta t\left[Q_T - \Theta V\right] + \Lambda\left(mS_oH_l - m'S_o'H_l'\right)V. \qquad (8.1)$$

Здесь $\psi = m[S\rho_wC_w + S_oc_o] + (m_0 - m)\rho_pC_p + (1 - m_0)\rho_fC_f$ — объемная теплоемкость ячейки (`psi_cell`; объем, потерянный порами, имеет свойства кристаллического парафина), $c_o = \rho_o(C_ow_o + C_p(w_p + w_{ps}))$, $Q_T$ — тепловой приток граней и скважин, $\Theta$ — потери тепла (разд. 8.2). Последнее слагаемое — скрытая теплота: растворенный парафин имеет энтальпию на теплоту плавления выше кристаллического, поэтому убыль носителя $H_l$ (кристаллизация) греет, рост — охлаждает; $\Lambda = \rho_o\,\mathrm{latent\_heat}$ (калориметрическая теплота Вона, не выведенная из подогнанной $\alpha$); штрихом отмечены величины нового слоя. В коде формула записана как $T^{n+1} = T^n + \frac{\Delta t}{\psi^{n+1}V}[\ldots - T^nV(\psi^{n+1}-\psi^n)/\Delta t]$, что тождественно (8.1).

**Что берется с какого слоя.** $T$, $T_0$, $S$, $m$, $w_p$, $w_{ps}$ в $\psi^n$ — слой $n$; $\psi^{n+1}$ — по $m'$, $S'$, $w_p'$, $w_{ps}'$ нового слоя (поэтому температура идет последней в проходе 3). Конвективные потоки — по давлению нового слоя, доли фаз и температура апвинда — слой $n$.

**Источник скважины** (`temperature_source`): $\rho_wC_wq_wT_{well} + h_{oil}(T_{cell})q_o$; $T_{well} = T_{inj}$ у нагнетательной, $T$ ячейки у добывающей; плюс Joule–Thomson $(p_w - p_c)[(1-\beta_wT_K)q_w + (1-\beta_oT_K)q_o]$.

**Сезонная закачка.** При `T_inj_amplitude` $\ne 0$ `Solver.start` меняет $T_{inj} = T_{inj,0} - A\cos(2\pi t/T_{per})$ каждый шаг (зимний минимум в начале).

## 8.2. Потери тепла в кровлю и подошву (`heat_losses`)

Член $\Theta$ — `Temperature.heat_loss_rate`, [Вт/м³]; метод выбирает целочисленная константа, ветка сворачивается при компиляции.

- **0** — нет.
- **1 — Ловерье.** Полубесконечный массив пород с перегревом на границе: плотность потока $K_{ff}(T - T_{init})/\sqrt{\pi\alpha_{ff}t}$ с единицы площади (Карслоу–Егер); двойка — кровля и подошва, деление на $h$ — переход к объему:
  $$\Theta = \frac{2K_{ff}(T - T_{init})}{h\sqrt{\pi\alpha_{ff}t}}. \qquad (8.2)$$
  Без состояния; время $t$ — от начала расчета, а не от прихода фронта (завышает длительность прогрева пород под уже пройденными ячейками); при $t \le 0$ нуль; в остывшей ячейке знак отрицательный — породы возвращают тепло.
- **2 — Винсом–Вестервельд** (умолчание). Точный поток — свертка всей истории температуры ячейки с ядром $1/\sqrt{t-\tau}$, $O(t)$ работы на ячейку. Вместо нее в породе принят пробный профиль с двумя свободными параметрами:
  $$T(z) - T_{init} = (\Delta T_b + p z + q z^2)e^{-z/d},\qquad d = \tfrac12\sqrt{\alpha_{ff}t}. \qquad (8.3)$$
  Параметры $p$, $q$ находятся каждый шаг из двух условий: профиль удовлетворяет уравнению теплопроводности на границе и интеграл профиля равен фактически накопленному в породе теплу:
  $$\frac{\Delta T_b}{d^2} - \frac{2p}{d} + 2q = \frac{\dot T}{\alpha_{ff}},\qquad \Delta T_b d + p d^2 + 2q d^3 = E_{ff}. \qquad (8.4)$$
  Исключение $q$ дает замкнутую формулу $p = (E_{ff} - d^3\dot T/\alpha_{ff})/(3d^2)$, $q$ в поток не входит. Здесь $\Delta T_b = T - T_{init}$, $\dot T = (T - T_0)/\Delta t$. Поток с единицы площади $K_{ff}(\Delta T_b/d - p)$, возврат $\Theta = 2\cdot\mathrm{flux}/h$, затем состояние обновляется на месте: $E_{ff} \mathrel{+}= \mathrm{flux}\,\Delta t/M_{ff}$, $M_{ff} = c_{ff}\rho_{ff}$ ($E_{ff}$ обновляется **после** использования в $p$; гонки нет — ячейка пишет свой $[i,j]$). Единственное поле состояния — `Solver.E_ff`. На ступеньке температуры рекурсия сходится к автомодельному режиму $E_{ff} = (24/11)\,d\,\Delta T_b$ и дает поток на 3.3 % ниже точного (`tests/test_heat_losses.py`). Разность $T - T_0$ накоплена за предыдущий шаг, а делится на текущий — расхождение ограничено ростом шага `dt_growth`.
- **3 — термостат** (опыты на керне): $\Theta = h_{v,bath}(T - T_{init})$, теплообмен по Ньютону через манжету.

## 8.5. Тепловое неравновесие (`thermal_nonequilibrium`)

Ядро `Thermal_ltne.temperature_equation_ltne` считает температуру флюидов тем же балансом (8.1), но с теплоемкостью без породы $c_f = \psi - c_{rock}$, $c_{rock} = (1-m_0)\rho_fC_f$; теплопроводность и потери целиком отнесены к уравнению флюидов. Затем флюид и порода (температура породы — `kx['ts']`) обмениваются теплом с **точной** экспонентой за шаг, а не явным шагом по жесткой константе:

$$T_{eq} = \frac{C_fT_f + C_sT_s}{C_f + C_s},\quad \Delta = (T_f - T_s)\,e^{-h_v(1/C_f + 1/C_s)\Delta t},\quad T_f' = T_{eq} + \frac{C_s\Delta}{C_f+C_s},\quad T_s' = T_{eq} - \frac{C_f\Delta}{C_f+C_s}. \qquad (8.5)$$

Энергия сохраняется точно. Коэффициент обмена $h_v = 6(1-m)/d_g\cdot Nu\,\lambda_f/d_g$, $Nu = 2 + 1.1Re^{0.6}Pr^{1/3}$ (Wakao–Kaguei), $Re = \rho u d_g/\mu$, $Pr = c_f\mu/\lambda_f$, $u = (\lambda_o + \lambda_w)|\nabla p|$, $d_g$ — `kin[LTNE_DG]`. Функция возвращает полную $\psi$ (с породой) для условия Куранта по температуре (оно менее строго, чем по $c_f$).

# 9. ПЕРЕНОС КОМПОНЕНТОВ

## 9.1. Дискретизация

Все компоненты нефтяной фазы движутся с нефтью с одной скоростью, схема одна — явная, МКО, разность против потока. Накапливается «масса на единицу объема породы» $m S_o w_c$, а затем делится на $m^{n+1}S_o^{n+1}$ нового слоя (`components_equation`):

$$w_c^{n+1} = \frac{m^nS_o^nw_c^n + \Delta t\left[\frac1V\left(\sum_f F^o_f\,w_{c,up} + q_o w_c\right) - s_c\right]}{m^{n+1}S_o^{n+1}}. \qquad (9.1)$$

Потоки $F^o_f$ — нефтяные потоки граней из `flows_in_cells`: при $F>0$ (приток) состав берется у соседа (или из `bc_Wc` при Дирихле), при $F<0$ (отток) — свой. Скважина: $q_o w_c$ у добывающей (у нагнетательной $q_o = 0$). Консервативно для каждого компонента (баланс до $10^{-16}$). Стоки $s_c$ — **нового** слоя ($q_{p1}$, $q_{p2}$ …): иначе парафин уходил бы из фазы на шаг позже, чем терялся поровый объем.

Если ячейка промыта ($m^{n+1}S_o^{n+1} \le 10^{-12}$), все доли и $H_l$ обнуляются. После деления: $w = \min(\max(w, 0), 1)$ для массовых долей; число флокул сверху не ограничивается. Зажим защищает от отрицательных долей, но при срабатывании нарушает баланс массы — он не должен срабатывать (отсюда ограничители подводом в разд. 13).

## 9.2. Ветка LEAN

Если групп парафина одна, асфальтенов нет и нет кинетики (`layout.LEAN`), используется облегченная ветка: переносится одна величина $w$ (сумма растворенного и взвешенного парафина), сток $s = (\rho_p/\rho_o)(q_{p1} + q_{p2})$, накопление отложений $D \mathrel{+}= \Delta t\,\rho_o s$, зажим $[0, 1]$, и равновесие — замкнутая формула `single_split` (разд. 10.1). Поле $W_s$ не пишется. Результат — $new\_W_p$, $new\_W_{ps}$, $new\_H_l = L_{rel}\,w_{dis}$.

## 9.3. Общий путь

Порядок внутри `components_equation` при нескольких компонентах:

1. **Стоки парафина по группам.** Захват кристаллов: $s_{cap} = (\rho_p/\rho_o)(q_{p1} + q_{p2})\,W_{s,k}/\sum W_{s}$, при выносе ($q_w < 0$) — по составу осадка $D_k/\sum D$. Добавка при кинетике: $(\rho_p/\rho_o)(q_w\,w^{sh}_k + q_g\,g^{sh}_k)$ — стеночная кристаллизация и старение берут растворенный парафин в долях групп. Накопление $D_k \mathrel{+}= \Delta t\rho_os_k$. Новая масса $\mathrm{mso}\cdot W_{c,k} - \Delta t\,s_k$; в компонент взвеси (при `wax_kinetics`) вычитается только захват $s_{cap}$.
2. **Асфальтены и смолы** (если они переносятся): стоки $(\rho_{ad}/\rho_o)(1-f_r)q_{pa}$ для флокул и $(\rho_{ad}/\rho_o)f_rq_{pa}$ для смол; при выносе ($q_{pa} < 0$) — по составу осадка $D_{af}/(D_{af} + D_r)$. Растворенные асфальтены стока не имеют.
3. **Адсорбция:** $g_a \mathrel{+}= \Delta t\rho_os_{ada}$, убыль растворенных асфальтенов и смол из фазы.
4. **Агрегация:** число флокул $N_F$: $\mathrm{mso}\,N_F - \Delta t\,s_{af}N_F/w_{af}$.
5. **Перенос** по граням и скважине — (9.1).
6. **Промывка** и **зажим** (9.1).
7. **Равновесие парафина:** без `wax_kinetics` — `sle_split` (разд. 10.2); с `wax_kinetics` — релаксация взвеси к равновесию (разд. 10.5). Результат — $new\_W_p$, $new\_W_{ps}$, $new\_H_l$.
8. **Асфальтены:** предел растворимости и релаксация флокул (разд. 12).
9. **Агрегация:** новые первичные частицы и шаг Смолуховского (разд. 12.4).

Замыкание объема: накопленные отложения замыкают пористость, $\sum_kD_k/\rho_p + (D_{af} + D_r)/\rho_{ad} = m_0 - m$ (при условии, что отрицательные значения не зажимались).

# 10. РАВНОВЕСИЕ ПАРАФИНА В ЯЧЕЙКЕ (SLE)

Задача: по суммарным массовым долям групп $w_k$ (растворенная + взвешенная) при температуре $T$ и давлении $p$ найти растворенную и взвешенную части, $w_k^{dis}$, $w_k^{sus}$, и носитель скрытой теплоты $H_l = \sum_k(L_k/\mathrm{latent\_heat})\,w_k^{dis}$. Вызывается в каждой ячейке каждого шага, поэтому никаких итераций по составу и выделений памяти: решение за $O(N_w^2)$.

## 10.1. Одна группа (`wax_characterization = 'single'`): замкнутая форма

Мольная доля насыщения группы $x^{sat}$ (разд. 10.3). Моли нефти без парафина на грамм: $n_0 = (1 - w)/M_o + n_{gas}$. Если группа насыщена, $x^{sat}$ связывает растворенное количество с остальными молями:

$$w^{dis} = \min\left(w,\ \frac{x^{sat}\,n_0}{1 - x^{sat}}\,M\right),\qquad w^{sus} = w - w^{dis}, \qquad (10.1)$$

при $x^{sat} \ge 1$ все растворено. Без давления и газа это формула (6.2) однокомпонентной модели (`single_wp_saturated` — эталон для тестов).

## 10.2. Несколько групп: multi-solid, жадный перебор активного множества

Каждая группа выпадает в свою чистую твердую фазу; условие равновесия группы $k$ из множества насыщенных $S$: $x_k^L = x_k^{sat}$, а недосыщенные группы остаются целиком в жидкости. Пусть $a_0 = n_{gas} + \sum_kw_k/M_k + (1 - \sum w)/M_o$ — все растворено, $b_0 = 1$. Для множества $S$ мольное количество жидкости

$$n_L = \frac{n_0 + \sum_{k\notin S}w_k/M_k}{1 - \sum_{k\in S}x^{sat}_k} \qquad (10.2)$$

— **точное** решение при заданном $S$ (растворенное количество каждой насыщенной группы $x_k^{sat}n_L$). Поиск $S$ жадный, без итераций (`sle_split`):

1. $a = a_0$, $b = 1$; для всех $k$ записывается $x_k^{sat}$ (в `sus[k]` — буфер результата, отдельный не нужен);
2. не более $N_w$ раз: среди групп вне $S$ с $w_k > 0$ и $x_k^{sat} < 1$ берется максимум порога $t_k = w_k/(M_kx_k^{sat})$ ($\infty$ при $x^{sat} = 0$);
3. если $t_{best}\,b \le a$ — стоп (группа не насыщена, поскольку количество группы, которое жидкость могла бы растворить, не меньше имеющегося); иначе группа входит в $S$, $a \mathrel{-}= w/M$, $b \mathrel{-}= x^{sat}$;
4. $n_L = a/b$; для групп из $S$ $w^{dis} = x^{sat}n_LM$, для остальных $w^{dis} = w$; $w^{sus} = w - w^{dis}$.

Обоснование: насыщение любой группы только уменьшает $n_L$, поэтому раз отвергнутый порог отвергается и на следующих шагах — перебор по убыванию порога находит точное активное множество. Этот алгоритм заменяет итерации Рачфорда–Райса, потому что твердые фазы чистые.

## 10.3. Мольная доля насыщения $x^{sat}_k(T, p)$

- **без `wax_eos`** (эффективные параметры, идеальный раствор): $\ln x_k^{sat} = -\frac{\Delta H_k}{R}\left(\frac1T - \frac1{T_{m,k}}\right)$; с `wax_pressure` добавляется поправка Пойнтинга $-\frac{\Delta v_k(p - P_{ref})}{RT}$; при положительном показателе $x^{sat} = 1$ (выше температуры плавления). $T$ — абсолютная с учетом `wax_pore_shift` (сдвиг в поровом пространстве);
- **с `wax_eos`:** $x_k^{sat} = \min(1, \exp(\text{eos\_interp}(\text{LNXSAT}_k, T - \text{wax\_pore\_shift}, p)))$ — билинейная интерполяция таблицы, построенной на PR (разд. 11.9).

## 10.4. Давление и газ (`wax_pressure`)

Включает три вещи: поправку Пойнтинга в $x^{sat}$, растворенный газ $n_{gas}(T, p)$ в мольном балансе жидкости и расширение таблиц на сетку давлений (без флага сетка — одна точка $P_{ref\_wax} = 101325$ Па). Газ: без `wax_eos` — линейно по давлению до $P_b$, $n_{gas} = N_{gas,b}\min(p/P_b, 1)$; с `wax_eos` — из таблицы `NG` (flash живой нефти). Без флага $n_{gas} = 0$ и ветка выброшена.

## 10.5. Кинетика кристаллизации (`wax_kinetics`)

Взвесь групп $W_{s,k}$ — отдельные компоненты $W_c[IS_0 + k]$, они переносятся с нефтью. После переноса равновесие `sle_split` дает равновесную взвесь $eq_k$ (пишется в `new_kx.weq`), и фактическая взвесь релаксирует к ней **точной** экспонентой $x_{new} = x_{eq} + (x - x_{eq})e^{-k\Delta t}$ со скоростью $k = $`K_CRYST` при $s < eq$ (кристаллизация) и $k = $`K_DISS` при $s > eq$ (растворение). Растворенная часть $w_k^{dis} = W_{c,k} - s_k$. Точная экспонента безусловно устойчива; ограничитель — $s_k \le \min(W_{s,k}, W_{c,k})$.

## 10.6. Твердый раствор в ячейке (`wax_solid_solution`)

Группы SCN выпадают в **один** твердый раствор (UNIQUAC Coutinho с идеальной жидкостью, плавление по Coutinho с твердо-твердым переходом, Пойнтинг при `wax_pressure`). Таблиц нет: насыщение группы зависит от состава твердого. `ss_split` — flash в ячейке (~10 мкс):

1. моли на грамм: $n_k = w_k/M_k$, $n_0 = n_{gas} + (1 - \sum w)/M_o$, $n_t = \sum n_k + n_0$; доли $z_k$, $z_0$; $\ln K^0_k = \frac{\Delta H_m}{RT}(1 - T/T_m) + [T < T_{tr}]\frac{\Delta H_{tr}}{RT}(1 - T/T_{tr}) + \frac{\Delta v}{R}\frac{p - P_{ref}}{T}$ (идеальная $1/x^0$);
2. **старт** состава твердого всегда идеальный $x^S = z\,e^{\ln K^0}$ нормированный: решений flash с одной твердой фазой бывает несколько, и старт со взвеси прошлого слоя давал бы ответ, зависящий от истории ячейки;
3. **incipient** (`_ss_incipient`): подстановка $W_k = z_k\exp(\ln K^0_k - \ln\gamma_k(x^S))$, $x^S = W/\sum W$, не более 300 итераций, допуск $10^{-11}$. Если $\sum W \le 1$ — твердого нет;
4. иначе внешний цикл (до 500 итераций): $K_k = \exp(\ln K_k^0 - \ln\gamma_k(x^S))$; доля твердого $\psi$ — корень уравнения Рачфорда–Райса с нелетучим растворителем $f(\psi) = \sum_kz_k\frac{K_k - 1}{1 + \psi(K_k - 1)} - \frac{z_0}{1-\psi} = 0$ (убывающая функция на $(0,1)$), защищенный Ньютон: шаг вне текущего отрезка заменяется бисекцией, остановка $|\Delta\psi| < 10^{-15}$, не более 100 итераций, старт — $\psi$ предыдущего витка; затем $x_k^S = K_kz_k/(1 + \psi(K_k - 1))$ нормируется, остановка при $\max|\Delta x^S| < 10^{-11}$;
5. $w_k^{sus} = \min(w_k, \max(0, \psi\,n_t\,x_k^SM_k))$.

Эталон — `thermo.solids.UniquacSolidWax(liquid='ideal')`, совпадение 2e-12 (`tests/test_solid_solution.py`). Расслоение твердого раствора на несколько фаз не поддержано.

## 10.7. Температура начала кристаллизации (WAT)

`Thermo_wax.wat_cell` — диагностика выгрузки, шагом не вызывается:

- **замкнутая форма** (без `wax_eos` и `wax_solid_solution`): при всем растворенном $x_k = (w_k/M_k)/n_L$ и $T_k = \dfrac{\Delta H_k/R + \Delta v_k(p - P_{ref})/R}{\Delta H_k/(RT_{m,k}) - \ln x_k}$, $WAT = \max_kT_k - 273.15 + $`wax_pore_shift`;
- **с `wax_eos` или `wax_solid_solution`:** бисекция по $T$ ровно 40 раз на $[T_{lo}, T_{hi}]$ (разрешение ~1e-10 °C) по предикату «ячейка насыщена» (для твердого раствора — `ss_split` дает взвесь; иначе есть группа с $w_k > M_kx_k^{sat}n_L$). Предполагается монотонность насыщения по температуре; за сеткой возвращается край.

# 11. УРАВНЕНИЕ СОСТОЯНИЯ ПЕНГА–РОБИНСОНА И ТЕРМОДИНАМИЧЕСКИЕ ТАБЛИЦЫ

Все, что в этом разделе, работает на numpy/scipy при импорте пакета (и только с флагами `wax_eos` / `asph_nghiem`), для сравнений в `experiments/уравнение_состояния` и как эталон тестов. Шаг по времени читает лишь готовые таблицы (разд. 11.9). Единицы — СИ: $T$ в K, $p$ в Па.

## 11.1. Параметры компонента и смешение (`thermo/eos.py`)

Уравнение PR (Peng, Robinson, 1976): $p = \dfrac{RT}{v - b} - \dfrac{a(T)}{v(v+b) + b(v-b)}$. Для компонента $i$ с критическими $T_c$, $p_c$ и ацентрическим фактором $\omega$:

$$b_i = 0.0777960739\frac{RT_{c,i}}{p_{c,i}},\qquad \sqrt{a_i(T)} = \sqrt{0.45723553\frac{R^2T_{c,i}^2}{p_{c,i}}}\left[1 + m_i\left(1 - \sqrt{T/T_{c,i}}\right)\right], \qquad (11.1)$$

$$m_i = \begin{cases}0.37464 + 1.54226\omega - 0.26992\omega^2, & \omega \le 0.491,\\ 0.379642 + 1.48503\omega - 0.164423\omega^2 + 0.016666\omega^3, & \omega > 0.491\ \text{(PR78, Robinson, Peng, 1978)}.\end{cases}$$

Правила смешения Ван-дер-Ваальса с коэффициентами парного взаимодействия $k_{ij}$: $a = \sum_{ij}x_ix_j(1 - k_{ij})\sqrt{a_ia_j}$, $b = \sum x_ib_i$; безразмерные $A = ap/(RT)^2$, $B = bp/(RT)$. Матрица $k_{ij}$ нулевая, кроме пар «газ — все остальное» (`kij_gas`, подбирается, разд. 11.9) и «газ — асфальтены» (`eos_kij_asph_gas` = 0.4, Tabzar 2018: держит колокол выпадения асфальтенов; при нуле ниже $P_b$ растворения нет).

## 11.2. Фактор сжимаемости: кубическое уравнение

$$Z^3 - (1 - B)Z^2 + (A - 2B - 3B^2)Z - (AB - B^2 - B^3) = 0. \qquad (11.2)$$

Решается `numpy.roots` (собственные значения сопровождающей матрицы), формулы Кардано в коде нет. Оставляются корни с $|\mathrm{Im}| < 10^{-9}$ и $Z > B + 10^{-12}$ (физический корень лежит правее $B$), сортировка по возрастанию. Нет ни одного корня — `RuntimeError`. Выбор корня (`z_factor`): `'liquid'` — наименьший, `'vapor'` — наибольший; при единственном корне возвращается он **независимо от запрошенной фазы** (метка может не соответствовать физической фазе — отсюда `live_liquid`, разд. 11.9); `'auto'` — корень с наименьшей безразмерной остаточной энергией Гиббса

$$g(Z) = (Z - 1) - \ln(Z - B) - \frac{A}{2\sqrt2B}\ln\frac{Z + (1 + \sqrt2)B}{Z + (1 - \sqrt2)B}. \qquad (11.3)$$

## 11.3. Коэффициент фугитивности

$$\ln\varphi_i = \frac{b_i}{b}(Z - 1) - \ln(Z - B) - \frac{A}{2\sqrt2B}\left(\frac{2\psi_i}{a} - \frac{b_i}{b}\right)\ln\frac{Z + (1 + \sqrt2)B}{Z + (1 - \sqrt2)B}, \qquad (11.4)$$

$\psi_i = \sqrt{a_i}\sum_jx_j(1 - k_{ij})\sqrt{a_j}$ (Michelsen, Mollerup, 2007). `pure(i)` строит PR для одного компонента — опорная чистая жидкость для твердой фазы (разд. 11.8).

## 11.4. Тест устойчивости по касательной плоскости (Michelsen)

Устойчив ли состав $z$ как одна фаза? Вводятся $d_i = \ln z_i + \ln\varphi_i(z)$ и пробная фаза с неотнормированными молями $W_i$; стационарные точки удовлетворяют

$$\ln W_i = d_i - \ln\varphi_i(w),\qquad w = W/\textstyle\sum W. \qquad (11.5)$$

Алгоритм (`stability_test`): начальные приближения по Вильсону, $K_i^{W} = \dfrac{p_{c,i}}{p}\exp[5.373(1+\omega_i)(1 - T_{c,i}/T)]$: «паровой» старт $W = zK$ и «жидкостный» $W = z/K$. Последовательные подстановки (без ускорения): $\ln W^{new}_i = d_i - \ln\varphi_i(W/\sum W)$ до $\max|\ln W^{new} - \ln W| < 10^{-12}$, не более 1000 итераций (после выхода сходимость не проверяется). Нетривиальная точка: $w$ не совпадает с $z$ (`atol` = 1e-5). **Нестабильность — $\sum W > 1 + 10^{-7}$**; из двух стартов выбирается точка с наибольшей суммой. Результат — пробная фаза $w$ или `None` (устойчиво).

**Режим `vapor_only`** (используется для нефти): только паровой старт, и пробная фаза должна быть газом по правилу Кея ($\sum w_iT_{c,i} < T$); иначе она отбрасывается. Зачем: при большом $k_{ij}$ асфальтены–легкие PR делит живую нефть выше давления насыщения на две жидкости (асфальтеновую и обедненную), к последней сходится и паровой старт. Это расслоение в модели описывает твердая фаза Nghiem (разд. 11.8), поэтому жидкость–жидкость отключается. Ограничение: правило Кея отсекает и жирный газ с $T_{pc} > T$; у нефти модели газ — метан, $T_{pc} = 191$ K. Строже — трехфазный flash.

## 11.5. Flash пар — жидкость

**Уравнение Рачфорда–Райса** (1952) для доли пара $\beta$:

$$\sum_iz_i\frac{K_i - 1}{1 + \beta(K_i - 1)} = 0. \qquad (11.6)$$

Функция монотонна по $\beta$, поэтому граничные случаи отсекаются без поиска корня: $\sum z(K - 1) \le 0$ — $\beta = 0$; $\sum z(K-1)/K \ge 0$ — $\beta = 1$; иначе `brentq` на $[0, 1]$, `xtol` = 1e-15. Расширенный (отрицательный) flash не используется.

**Последовательные подстановки** (`flash`):

1. тест устойчивости (разд. 11.4); если пробной фазы нет — одна фаза, метка «пар» ставится, если корень один и $Z > 0.5$ либо $Z$ — наибольший из корней;
2. старт $K = \max(w/z, 10^{-200})$ ($K$ тяжелых групп и асфальтенов в холодном газе уходят в машинный ноль, иначе деление на нуль в (11.6));
3. цикл до 500 раз: $\beta$ из (11.6), $x = z/(1 + \beta(K - 1))$, $K^{new} = \exp[\ln\varphi_i^L(x) - \ln\varphi_i^V(Kx)]$, остановка при $\max|\ln(K^{new}/K)| < 10^{-12}$; ускорений и демпфирования нет;
4. вырождение в одну фазу, если $\max|K - 1| < 10^{-4}$, либо $\beta \le 10^{-9}$, либо $\beta \ge 1 - 10^{-9}$.

Возвращаются $\beta$, составы жидкости $x$ и пара $y = Kx$.

## 11.6. Давление насыщения

`bubble_pressure`: **бисекция по $\ln p$** на $[10^5, 10^8]$ Па до $\Delta\ln p \le 10^{-6}$ (около 23 вызовов flash) по **признаку** «flash дает две фазы» (`vapor_only`, $0 < \beta < 1$), а не по невязке $\sum z_iK_i = 1$: выше давления насыщения подстановки сходятся к тривиальному решению, и невязка обнуляется, не будучи корнем. Если на границах отрезка признак не меняется — `ValueError`.

## 11.7. Характеризация и свойства твердых фаз

**Свойства фракций** (`thermo/characterization.py`): н-алканы по молярной массе — Riazi: $T_b = 1070 - \exp(6.98291 - 0.02013M^{2/3})$, $SG = 0.85 - \exp(92.22793 - 89.82447M^{0.01})$; нефтяная фракция по $(M, SG)$ — Riazi–Daubert (1987) для $T_b$ и Riazi–Daubert (1980) для $T_c$, $p_c$; ацентрический фактор — Kesler–Lee (две ветви по $T_{br} = T_b/T_c$, граница 0.8). Группа SCN молярной массы $M$ — н-алкан с $n = (M - 2.016)/14.027$. Гамма-распределение (`wax_characterization = 'gamma'`): доля SCN-группы $= F(M + 7.0135) - F(M - 7.0135)$ через верхние неполные гамма-функции `gammaincc` (хвост не теряет точность); при $\alpha = 1$ получается экспонента с наклоном `scn_slope`. Свойства плавления: по Won (`eos_melting = 'won'`: $T_m = 374.5 + 0.02617M - 20172/M$, без твердо-твердого перехода) либо по Coutinho (`'coutinho'`: $T_m$, $T_{tr}$ — экспоненциальные формулы по $n$; $\Delta H_m$, $\Delta H_{tr}$ — полиномы при $n < 42$, $\Delta H_m = 3.7791n - 12.654$ при $n \ge 42$, перехода нет; подписи (A4) и (A6) в статье перепутаны, сверено с Broadhurst).

**Плавление чистого компонента:**

$$\frac{\Delta G_{fus}}{RT} = \ln\frac{f^{0,L}}{f^{0,S}} = \frac{\Delta H_{fus}}{RT}\left(1 - \frac{T}{T_{fus}}\right) + [T < T_{tr}]\frac{\Delta H_{tr}}{RT}\left(1 - \frac{T}{T_{tr}}\right) - \frac{\Delta C_p}{R}\left[\left(\frac{T_{fus}}{T} - 1\right) - \ln\frac{T_{fus}}{T}\right]. \qquad (11.7)$$

Скачок теплоемкости (Pedersen) есть в `fusion_ln_ratio`, но в таблицы не идет: поверх перехода он ухудшает WDT синтетических смесей. При $T = T_{fus}$ имеем $\Delta G = 0$: WAT чистого компонента точно равна его $T_{fus}$.

## 11.8. Твердые фазы на PR

**Multi-solid** (Lira-Galeana, Firoozabadi, Prausnitz, 1996; `MultiSolidWax`). Каждый выпадающий компонент — своя чистая твердая фаза: $f_i^L(T, p, x) = f_i^{0,S}(T, p)$. Опора — **чистая жидкость из того же уравнения состояния**, давление в твердой фазе — поправкой Пойнтинга на скачок объема (Pan, Firoozabadi, Fotland, 1997):

$$\ln f_i^{0,S} = \ln\left[\varphi_i^{pure,L}(T, p)\,p\right] - \frac{\Delta G_{fus,i}}{RT} - \frac{\Delta v_i(p - p_{ref})}{RT}. \qquad (11.8)$$

Без последнего слагаемого твердое получает объем жидкости, и $d\,WAT/dp$ выходит 0.017 °C/МПа вместо 0.15–0.23 у Sandyga. В таблицах $\Delta v_i$ — физический (из плотностей жидкого и кристаллического парафина, ~0.13 $v_L$), а не эффективный `wax_dv_frac`: тот подобран вместе с заниженной эффективной теплотой. Фугитивность жидкости $\ln f_i^L = \ln x_i + \ln\varphi_i^L(x) + \ln p$.

**Равновесие при фиксированном множестве осадков** $S$ (`_solve_set`): для $i \in S$ $x_i = \exp(\ln f_i^{0,S} - \ln\varphi_i(x) - \ln p)$, количество жидкости $L = z_{non}/(1 - \sum_Sx_s)$, остальные $x_{non} = z/L$. Простые подстановки до $\max|\Delta x| < 10^{-12}$, не более 300 итераций; если $1 - \sum_Sx_s \le 10^{-12}$ — набор несовместим. Твердые моли $s_i = z_i - Lx_i$.

**Активное множество** (`precipitate`, не более $N_w + 5$ витков): пока есть компоненты вне $S$ с пересыщением $\ln f^L - \ln f^S > 10^{-9}$, в $S$ добавляется самый пересыщенный; после каждого добавления равновесие решается заново, и компоненты с $s_i \le 10^{-12}$ убираются из $S$. Остановка, когда пересыщенных нет.

**WAT** — `brentq` по $T$ на $[150, 450]$ K, `xtol` = $10^{-6}$, для $f(T) = \max_k(\ln f^L_k - \ln f^S_k)$ при составе $z$.

**Идеальный твердый раствор** (Won, 1986; `IdealSolidSolutionWax`) — только для сравнения: $K_i = \exp(\Delta G/RT)$, доля твердого — корень Рачфорда–Райса (`brentq`, `xtol` = 1e-14).

**Твердый раствор UNIQUAC Coutinho** (`UniquacSolidWax`) — только в сравнениях и в ядре ячейки при `wax_solid_solution` (разд. 10.6): $r = 0.1n + 0.0672$, $q = 0.1n + 0.1141$, $Z = 6$, энергия решетки $\lambda_{ii} = -(2/Z)(\Delta H_{sub} - RT)$, $\Delta H_{sub} = \Delta H_{vap} + \Delta H_m + \Delta H_{tr}$, $\Delta H_{vap} = 5.0n + 1.4$ кДж/моль, энергия пары — по более короткой молекуле; $\ln\gamma$ — стандартный UNIQUAC; внешний цикл flash — до 500 итераций, допуск $10^{-11}$, без демпфирования.

**Асфальтены Nghiem** (Nghiem et al., 1993; Qin et al., 2000; `NghiemAsphaltene`). Асфальтены — отдельный компонент PR с индексом `idx`, выпавшая фаза — чистая твердая:

$$\ln f_s(T, p) = \ln f_s^* + \frac{v_s(p - p^*)}{RT}. \qquad (11.9)$$

Опорная фугитивность калибруется по давлению начала осаждения: $\ln f_s^* = \ln x_a + \ln\varphi_a^L + \ln p$ в точке $(T^*, p_{onset})$ по составу $x$ (`calibrate_onset`): в этой точке жидкость ровно насыщена. Зависимости $f_s^*$ от $T$ нет — температура входит только через $\varphi_a$. Растворимость при $(T, p)$ (`solubility`): остальной состав фиксируется пропорционально $x$ (`rest`), итерация $x_a \leftarrow \min(1, \exp(\ln f_s - \ln\varphi_a(x_a) - \ln p))$, где состав $= rest(1 - x_a) + x_a$, старт $x_a = x[idx]$, остановка при $|\Delta x_a| \le 10^{-12}x_a$, не более 200 итераций, без демпфирования. Выпавшее: $s = x_a - L x_a^{sat}$, $L = (1 - x_a)/(1 - x_a^{sat})$; при недосыщении и при $x_a^{sat} \ge 1$ — 0.

## 11.9. Таблицы для ядер (`thermo/tables.py`)

Числа в ядра попадают только таблицами. Сетка — `eos_T_grid` × `eos_P_grid` (по умолчанию $T$: 0…150 °C, 31 узел; $p$: 0.1…40 МПа, 21 узел; без `wax_pressure` — одна точка $P_{ref\_wax}$, $N_P = 1$). Без `wax_eos` и `asph_nghiem` таблицы нулевые, ветки ядер свернуты.

**Флюид** (`oil_fluid`): на 1 г дегазированной нефти — метан (мольное газосодержание $N_{gas,b}$), растворитель (критические свойства Riazi–Daubert по $M_o$ и $SG = \rho_o/999$), группы парафина (по н-алканам) и, с асфальтенами, псевдокомпонент (Tc = 1100 K, Pc = 0.8 МПа, $\omega$ = 1.0, $M_{asph} = v_a\rho_{asph}$).

**Калибровки при импорте:**

- **$k_{ij}$ газ — тяжелые** (`calibrate_kij_gas`): `brentq` на $[-0.3, 0.3]$ по $f(k) = \ln[P_b^{EOS}(init\_T, k)/P_{bubble}]$, `xtol` = 1e-7; $P_b^{EOS}$ — из `bubble_pressure` (разд. 11.6). Если знаки на концах совпадают — `ValueError` с подсказкой про `Rs_bubble` и `eos_gas_*`. Документированный результат: $k_{ij} \approx -0.003$.
- **Опорная фугитивность Nghiem** — по $P_{onset\_asph}$ при `init_T` (разд. 11.8).
- **Кривая выпавших асфальтенов** (`asph_curve`, `fit_nghiem_curve`): выпадение задает разность парциального объема асфальтенов в нефти $v_a = RT\,\partial\ln\varphi_a/\partial p + RT/p$ (центральная разность, $h = 10^{-3}P_{onset}$) и $V_s$ (доли процента); подбор $V_s = q\,v_a$ методом наименьших квадратов по множителю $q$ (старт 1.01, границы 0.9–1.2); с газом $k_{ij}$ асфальтены–газ перебирается по `linspace(0, 0.5, 51)` (минимумов несколько, узкие) с подбором $V_s$ на каждом значении, затем совместное уточнение `least_squares` по $(q, k_{ij})$.
- Хиршберговский $v_a$ по кривой — `oil_composition._fit_v_asph` (разд. 12.1).

**Построение** (`build_tables`): двойной цикл по $(T, p)$; в каждом узле **последовательно**: (1) `live_liquid` — flash живой нефти (`vapor_only`); однофазное состояние всегда считается жидкостью (метка «пар» по корню $Z$ для нефти под давлением ошибочна), растворенный газ $n_{gas} = (1 - \beta)x_gN_t$; (2) multi-solid на жидкости: равновесная жидкость $x_{ref}$ (`precipitate`); (3)

$$\ln x_k^{sat}(T, p) = \ln f_k^{0,S}(T, p) - \ln p - \ln\varphi_k^L(x_{ref}). \qquad (11.10)$$

Для асфальтенов — `nghiem_lnwamax`: $\ln w_{a,max} = \ln\left[\dfrac{x_a^{sat}M_{asph}}{\sum_{dead}x_i^{sat}M_i}\right]$ — логарифм предельной массовой доли растворенных асфальтенов на дегазированную нефть, парафин при этом считается растворенным целиком. Состав в $\varphi$ заморожен на исходной нефти; равномерная сетка размазывает излом у $P_b$ на один шаг сетки. Газосодержание $n_{gas}(T, p)$ (`NG`) и, при `wax_pressure`, объем свободного газа на объем нефти (`GASV`, PVT-диагностика, `thermo/pvt.py`: $R_s$, $B_o$, $B_g$, вязкость газа по Lee–Gonzalez–Eakin) идут в ту же таблицу. Уравнения фильтрации PVT-величины не читают.

**Кеш.** Сборка с газом и подбором по кривой — 10–20 с на процесс, а таблицы зависят только от исходников пакета и версий numpy/scipy. Файл `paraphin/__pycache__/eos_tables_<ключ>.npz` с ключом $\mathrm{md5}(\text{штамп хеша исходников из } \_\_init\_\_,\ \text{numpy},\ \text{scipy})[:16]$; запись во временный файл и `os.replace` (параллельные процессы не видят недописанный); старые файлы удаляются.

**Чтение в ядре** — `eos_interp`: билинейная интерполяция по $(T, p)$, индексы зажимаются на границы сетки (за сеткой — значение с края), при $N_P = 1$ — линейная только по $T$. Нет ни flash, ни Ньютона в ячейке: цена состояния — четыре чтения из таблицы.

# 12. АСФАЛЬТЕНЫ И СОПУТСТВУЮЩИЕ МЕХАНИЗМЫ

## 12.1. Растворимость по Хиршбергу (`asphaltenes`, без `asph_nghiem`)

Предельная массовая доля растворенных асфальтенов (`Asphaltene.asph_soluble`):

$$\ln\varphi_a = \frac{v_a}{v_m} - 1 - \frac{v_a(\delta_a - \delta_m)^2}{RT},\quad \varphi = \min(1, e^{\ln\varphi_a}),\quad w_{max} = \frac{\varphi\rho_a}{\varphi\rho_a + (1 - \varphi)\rho_o}, \qquad (12.1)$$

$\delta$ в Па$^{0.5}$. Параметр растворимости мальтенов $\delta_m$ (`delta_maltene`): жидкие псевдокомпоненты смешиваются по массовым долям, затем масштабируются по плотности (правило одной трети: $\delta_{liq} \cdot= 1 + c_{oil}(p - P_{ref}) - \beta_{oil}(T - 25)$), затем смешиваются с растворенным газом по объемным долям. Параметр асфальтенов $\delta_a$ **калибруется** замкнутой формулой так, чтобы в точке $(P_{onset}, init\_T)$ начальная доля была ровно насыщающей: $\delta_a = \delta_m + \sqrt{RT(v_a/V_M - 1 - \ln\varphi_{a0})/v_a}$. При заданной `asph_curve` объем $v_a$ подбирается `least_squares` по $\ln v_a$ (границы $[\ln0.1\cdot10^{-3}, \ln10\cdot10^{-3}]$): невязка — выпавшее по Хиршбергу минус кривая, $\delta_a$ при каждом $v_a$ калибруется заново.

**Замечание.** Калибровка $\delta_a$ (`oil_composition.delta_maltene_py`) считает растворенный газ линейно по давлению всегда, а njit-версия $\delta_m$ использует `n_gas(T, p)`, равный нулю при `wax_pressure = False`. При включенном `wax_pressure` расхождения нет; при выключенном калибровка и рантайм считают $\delta_m$ с разным газом.

## 12.2. Растворимость по Nghiem (`asph_nghiem`, `asph_curve`)

$w_{max} = \min(1, \exp(\text{eos\_interp}(\text{LNWAMAX}, T, p)))$ — таблица (разд. 11.9). Состав ячейки при этом игнорируется: влияние смол и насыщения ячейки на растворимость теряется.

## 12.3. Флокуляция

Предел растворимости в ячейке (`Components.py`): $r = 1 - w_{wax} - a_{tot} - w_r$; $w_{max} = \text{asph\_soluble}(r F_{sat} + w_{dis},\ r(1 - F_{sat}),\ w_r,\ p,\ T)$ (растворенный парафин идет как насыщенная часть); равновесная доля флокул $af_{eq} = \max(a_{tot} - w_{max}, 0)$. Кинетика — точная экспонента (`floc_relax`): $w_{af} = af_{eq} + (w_{af}^* - af_{eq})e^{-k\Delta t}$, где $k = k_{floc}$ при $w_{af} < af_{eq}$ (выпадение) и $k_{redis}$ иначе; результат в $[0, a_{tot}]$, растворенные $= a_{tot} - w_{af}$ (сумма сохраняется). Безусловно устойчива.

## 12.4. Агрегация флокул (`asph_aggregation`)

Число флокул $N_F$ хранится как компонент $W_c[IN_F]$. Новые первичные частицы — выпавшее за шаг, $(af - af_{pre})/m_0$, $m_0 = \rho_{asph}\pi d_0^3/6$; при убыли флокул число уменьшается пропорционально; затем **точный** шаг уравнения Смолуховского с постоянным ядром $K = 8k_BT/(3\mu W)$:

$$N^{n+1} = \frac{N}{1 + \tfrac12KN\Delta t},\qquad (12.2)$$

результат ограничен сверху «все флокулы первичные», $N \le af/m_0$. Диаметр агрегата — фрактальный, $d = d_0\max(m/m_0, 1)^{1/D_f}$ (`floc_size`). При агрегации блокирование горл флокулами включается (`n_block_max = Nr`), иначе флокулы только сужают капилляры.

## 12.5. Адсорбция и удержание (`adsorption`)

Равновесие Ленгмюра $G_{eq} = G_{max}Kc/(1 + Kc)$; $G_{max} = g_{max}\,a_v$ по поверхности породы $surf_0$ (а не текущих каналов — иначе закупорка парафином вызывала бы десорбцию); $K(T)$ — по Вант-Гоффу; скорость $k_{ads} = k\,(T/T_{ref})\,\mu(T_{ref})/\mu(T)$ (Уилки–Чанг). Две формы кинетики (runtime `ADS_FILM`):

- **0 — со стороны твердой фазы**, $dG/dt = k_{ads}(G_{eq}(c) - G)$, шаг **неявный по концентрации в нефти ячейки** (`langmuir_ldf_step`): $dG = f(G_{eq}(c_{new}) - G)$, $c_{new} = c - dG/a$, $f = 1 - e^{-k\Delta t}$, $a = \mathrm{mso}_{dt}\Delta t\rho_o$ — масса нефти, доступной в ячейке за шаг, [кг/м³ породы]. Это квадратное уравнение $aKx^2 + (a + fK(G_{max} - G) - aKc)x - (ac + fG) = 0$ относительно $x = c_{new}$; берется положительный корень в устойчивой форме $2c_c/(b + \sqrt{D})$ ($c_c = ac + fG$). Явный шаг в заводненной зоне (остаточная нефть, $ac \ll G_{max}$) выбирал бы за шаг всю растворенную фракцию и на следующем шаге десорбировал — шаги колебались (шахматный узор $k/k_0$);
- **1 — пленочная**, $dG/dt = A(c - c^*(G))$, $c^*(G) = G/(K(G_{max} - G))$, неявный Эйлер (`langmuir_film_step`): $G_{new}$ — меньший корень $Kx^2 - (K(G_{max} + g) + a\Delta t(Kc + 1))x + KG_{max}(g + a\Delta t c) = 0$, всегда в $[0, G_{max})$; прирост ограничен растворенным, $dg \le \mathrm{mso}_{dt}\Delta t\,c\,\rho_o$.

Результат — объем слоя за единицу времени $dG/\rho_{ad}/\Delta t$. Смолы — с множителем емкости. Начальное удержание — равновесное при `init_T` (`ads_init_equilibrium`, разд. 3). Удержанные смолы и асфальтены не сужают каналы, а умножают $k$ на функцию повреждения (Civan): баланс массы исключает равномерный слой.

## 12.6. Смачиваемость (`wettability`)

Относительные проницаемости смешиваются по доле покрытия $\omega = \min(G_a/G_{max}, 1)$: $f_\alpha = (1 - \omega)f_\alpha^{WW} + \omega f_\alpha^{OW}$ (`calc_mobility_w`, `pf_w_mix`, `pf_o_mix`); то же при расчете продуктивности скважин и в таблице $dF/dS$ (разд. 15.2).

# 13. КОЛЬМАТАЦИЯ: ПУЧОК КАПИЛЛЯРОВ, ОСАЖДЕНИЕ, ПЕРЕНОС ПО РАДИУСАМ

## 13.1. Геометрия и интегралы

Сетка радиусов равномерная, $N_r$ узлов до $r_{max}$ (`geometry.py`); ширина контрольного объема $dr_{cv}$ — полусумма соседних отрезков. Функция $\varphi_0$ — логнормаль Косуги, нормирована $\sum\varphi_0dr_{cv} = 1$. Интегралы по кусочно-линейной $\varphi$ берутся **точно по отрезкам** (веса «шапочек» $w_1, w_2, w_4$, $w_{43}$ для $r^1, r^2, r^4, r^{4/3}$; билинейная форма $Q_{00}, Q_{01}, Q_{11}$ для $\int ru\varphi$). Извилистость $\eta = \sqrt{m_0\sum r^4\varphi_0dr/(8k_0\sum r^2\varphi_0dr)}$ согласует пучок с $k_0$: скорость в капилляре $u_m = |\nabla p|r^2/(8\eta\mu)$; в коде хранится $U_{m2} = u_m/r^2 = |\nabla p|/(8\eta\mu)$ (`calc_Um_r2`, с эффективной вязкостью нефти, то есть $\mu_p/\Phi$ при геле). Порог прохода $r_{pass} = D/(2\gamma)$, $n_{pass}$ — первый узел с $r \ge r_{pass}$: частицы закупоривают капилляры уже $r_{pass}$ (блокирование, $b(r)$) и оседают на стенках шире (сужение, $u < 0$). Для флокул $r_{pass,a} = D_{asph}/(2\gamma) = 1.25$ мкм меньше первого ненулевого узла — блокирования нет, только сужение (при $n_{pass,a} > 1$ — предупреждение).

## 13.2. Простое ядро: скорости и пористость (без кинетики)

**Скорости** (`calc_velocities_h`; только при $w_{ps} > $ `min_Wps_bound`, $S_o^{eff} = \max(0, 1 - S - S_{or})$): броуновская диффузия $D_p = diff\_mult\,\dfrac{k_BT_K}{3\pi D\mu_p}$ (вязкость жидкой основы, `mu_p`), $d_2 = 2D_p^2/L_k$;

- блокирование, $r < r_{pass}$: $b(r) = S_o^{eff}w_{ps}\dfrac{6\beta}{D^3}U_{m2}\,r^4$ — коэффициент (а не скорость) $b$, скорость блокирования $b\varphi$; $U_r = 0$;
- сужение, $r \ge r_{pass}$: $U_r = -S_o^{eff}w_{ps}\,(U_{m2}\,d_2)^{1/3}\,r^{1/3}$ — приближение Левека (один кубический корень на ячейку, $r^{1/3}$ из таблицы).

Хранится $b$, а не скорость, чтобы взять блокирование неявно в прогонке.

**Ограничители подводом** (`calc_qp_m_k_fi`). Запас нефти на шаг, за вычетом оттока: $\mathrm{mso}_{dt} = \max(mS_o/\Delta t - out_o/V, 0)$. Кристаллы: ожидаемый сток $\mathrm{sink} = (\rho_p/\rho_o)(i_w + q_{p2}^{est})$, $i_w = \max(-2\,to_m\int rU_r\varphi, 0)$, подвод $\mathrm{avail} = \mathrm{mso}_{dt}w_{ps}$; $lim_w = \min(1, \mathrm{avail}/\mathrm{sink})$. Для флокул — $lim_a$ с подводом $\mathrm{mso}_{dt}\min(w_{af}/(1 - f_r), w_r/f_r)$. Без ограничителя `components_equation` зажимала бы долю в нуле и создавала массу; ограничение шага по Куранту здесь не годится — у нагнетательной скважины оно загоняло шаг в `dt_min`.

**Профили** $u = lim_wU_r + lim_a u_a r^{1/3}$, $b = lim_wb$; здесь $to_m = m_0/\int r^2\varphi_0$ — множитель пересчета в пористость.

**Прогонка по радиусам** `update_fi_rows` (разд. 13.3), затем скорости по **фактическому** изменению $\varphi$:

$$\mathrm{blocked} = \Delta t\,lim_w\,to_m\sum w_2b\,\varphi^{new},\quad q_{p2} = lim_w\,to_m\sum plug_{cv}\,b\,\varphi^{new},$$
$$q_{narrow} = \max\left(\frac{to_m(\int r^2\varphi - \int r^2\varphi^{new}) - \mathrm{blocked}}{\Delta t},\ 0\right), \qquad (13.1)$$

$q_{pa} = q_{narrow}\,lim_ai_a/(lim_wi_w + lim_ai_a)$, $q_{p1} = q_{narrow} - q_{pa}$. Пористость и проницаемость:

$$m^{n+1} = m - (q_{p1} + q_{p2} + q_{pa})\Delta t,\qquad k^{n+1} = k_0\frac{\int r^4\varphi^{new}}{\int r^4\varphi_0}, \qquad (13.2)$$

и скорости масштабируются так, чтобы $(q_{p1} + q_{p2} + q_{pa})\Delta t = m - m^{n+1}$ выполнялось тождественно (на него опираются и насыщенность, и баланс парафина). Блокированный канал уходит из проводимости ($\varphi$), но **не из пористости**: его объем остается тупиковой пористостью, отдельного поля она не имеет — это $m - m_0\int r^2\varphi/\int r^2\varphi_0$. Пробка в горле — один кристалл на канал, вес `plug_cv`.

## 13.3. Перенос $\varphi$ по оси радиусов: неявная прогонка

Сужение во времени схема отражает не изменением $r$ (сетка фиксирована), а переносом $\varphi$ по оси радиусов:

$$\frac{\partial\varphi}{\partial t} + \frac{\partial(u\varphi)}{\partial r} = -b\varphi. \qquad (13.3)$$

`update_fi_rows`: неявный Эйлер, МКО на $dr_{cv}$, разность против потока по знаку скорости в узле; трехдиагональная система решается методом Томаса (прогонкой) за $O(N_r)$, итераций и допусков нет:

- диагональ $d_j = 1/\Delta t + |u_j|/dr_{cv,j} + b_j$;
- нижняя $c_j = -\max(u_{j-1}, 0)/dr_{cv,j}$, верхняя $e_j = \min(u_{j+1}, 0)/dr_{cv,j}$ (0 на последнем узле); на правом краю $\varphi = 0$ при $r_{max}$.

Матрица — M-матрица (диагональ не меньше суммы модулей внедиагональных, внедиагональные неположительны), поэтому $\varphi \ge 0$ **без зажима**. Блокирование взято неявно на диагонали: явная запись при большом $b\Delta t$ уводила бы $\varphi$ в минус. Сохраняется $\sum\varphi\,dr_{cv}$ с точностью до стока блокирования. Скретч прогонки (`rows.a`, `rows.b`) — в `rows[i]` (ловушка общего буфера, разд. 4.2). Сгущение сетки у $r_{pass}$ и $r_{max}$ точности не дает (ошибка сидит в 15–30 мкм, где масса $r^2\varphi$, $r^4\varphi$); помогает только $N_r$.

## 13.4. Выбор ядра: простое или кинетическое

`deposition_kinetics` (константа `constants.py`) — ИЛИ флагов `wax_kinetics`, `wall_transport`, `entrainment`, `asph_aggregation`, `snowball`, `adsorption`, `wettability`, `deposit_aging`, `thermal_nonequilibrium`, `pore_network`, `deposition_model != 'bundle'`. Если истинна — кольматацию считает `Deposition.calc_deposition` (пучок) или `calc_filtration` (глубинная фильтрация) в **проходе 1**, в каждой ячейке (без списка активных); иначе работает пара `Velocity_h` + `Qp_m_k_fi` в проходе 2. Различия:

| | простое ядро | кинетическое ядро |
|---|---|---|
| скорости $U_r$, $b$ | со слоя $n$ с лагом на шаг ($new\_U$ → следующий шаг) | по текущему слою (убирает колебания доли флокул) |
| пористость | $m - \sum q\Delta t$ с масштабом $scale$ тождества | $m - \sum q\Delta t$ по определению, $fi$ отдельно |
| механизмы | кристаллы (захват), флокулы (сужение) | + стеночная кристаллизация, вынос, растворение, адсорбция, старение, «снежный ком», сеть пор |
| ограничитель | $lim_w$, $lim_a$ | $lim_w$, $lim_a$ + свои запасы у каждого механизма |

Регрессия модели по умолчанию от ядра кинетики не зависит (побитово, `tests/test_regression_flags_off.py`). Проверки согласованности флагов — конец `constants.py` (`asph_aggregation`, `adsorption` требуют `asphaltenes`; `wettability` требует `adsorption`; `pore_network` требует пучок; `wax_solid_solution` требует группы и не сочетается с `wax_eos`; `asph_nghiem` требует `asphaltenes`; `P_onset_asph > P_bubble`).

## 13.5. Кинетическое ядро `calc_deposition`: порядок операций

В каждой ячейке (скретч — `rows[i]`):

1. Подготовка: $S_o^{eff}$, $\mathrm{mso}_{dt}$, моменты $\int r\varphi$, $\int r^2\varphi$, $\int r^4\varphi$; удельная поверхность текущих проводящих каналов $surf = 2\,to_m\int r\varphi$; множитель «снежного кома» $snow = 1 + A\max(m_0 - m, 0)/m_0$ (`snowball`, умножает $u$ и $b$ в `_particle_rows`); $c_0$ — пористость геля-отложения (`deposit_aging`), иначе 1.
2. **Кристаллы** ($w_{ps} > w_{min}$): `_particle_rows` строит профили $u_w$, $b_w$ (разд. 13.6); оценки стока и $lim_w$ — как в простом ядре, с диаметром кристалла `kin[D_CRYST]` и объемом пробки $(d_w/D)^3 plug_{cv}$.
3. **Флокулы** ($w_{af} > w_{min}$): диаметр $d_f$ (фрактальный при агрегации), $lim_a$; блокирование флокулами только при `asph_aggregation`.
4. **Стеночные стоки** `_wall_sinks` (разд. 13.7): $q_{wall}$, $q_{ada}$, $q_{adr}$, $q_{age}$.
5. **Вынос** (`entrainment`): $u_e(r) = \text{ENT\_RATE}\,(\tau_w/\tau_{cr} - 1)\,h(r)$ при $\tau_w = r|\nabla p|/(2\eta) > \tau_{cr}$ и толщине отложения $h > 0$ (Gruesbeck, Collins, 1982); порог $\tau_{cr}$ — разд. 13.8.
6. **Растворение осадка** (`deposit_dissolution`): при $q_{wall} < 0$ скорость расширения $u_{dis} = \min(-(q_{wall}/c_0)/surf,\ h/\Delta t)$ только там, где $h > 0$; не больше объема осадка парафина (масштабирование $f$); затем $q_{wall} := 0$ (растворение не считается дважды). Однородная скорость по поверхности расширяла бы и чистые каналы и уводила бы их за $r_{max}$ ($\varphi = 0$ на краю): $k$ падал бы до нуля при неизменных $m$ и осадке.
7. Равномерная скорость стеночной кристаллизации $u_{uni} = -(q_{wall}/c_0)/surf$.
8. **Ранний выход:** нет активных механизмов ($lim_w = lim_a = 0$, $u_{uni} = 0$, нет выноса) и $q_{age} = 0$ — поля копируются, $q$ обнуляются; при `entrainment` и `adsorption` ядро всегда активно.
9. **Суммарный профиль и прогонка:** $u = lim_wu_w/c_0 + lim_au_a + u_{uni} + u_e + u_{dis}$, $b = lim_wb_w + lim_ab_a$, `update_fi_rows`; толщина отложения $h^{new} = \max(h - u\Delta t, 0)$ (явно).
10. **Разбор фактической убыли каналов:** один проход по $r$ считает блокирование и пробки раздельно по кристаллам и флокулам; $narrow = to_m(\int r^2\varphi - \int r^2\varphi^{new})/\Delta t - \mathrm{blocked}$; масштаб $scale = (narrow + e_{ent} + e_{dis})/(e_w + e_a + e_{wall})$ ($scale = 0$ при неположительных числителе или знаменателе).
11. **Возврат выноса в нефть:** вынесенный объем распределяется по составу осадка: `ent_wax = min(ent_gel·c_dep, dep_wax_v/Δt)`, `ent_asph` аналогично.
12. **Итоговые скорости:** $q_{p1} = c_0e_wscale - ent_{wax}$, $q_w = c_0e_{wall}scale - c_0e_{dis}$, $q_{pa} = e_ascale + q_{pa,plug} - ent_{asph}$, $q_{p2}$ как посчитано; объем геля $v_{gel}^{new} = \max(v_{gel} + (e_w + e_{wall})scale\Delta t - e_{dis}\Delta t - ent_{wax}\Delta t/c_{dep}, 0)$.
13. **Пористость:** $m^{n+1} = m - (q_{p1} + q_{p2} + q_{pa} + q_w + q_{age} + q_{ada} + q_{adr})\Delta t$. Отрицательный сток — вынос или десорбция.
14. **Проницаемость:** без сети — $k_0\int r^4\varphi^{new}/\int r^4\varphi_0$; с `pore_network` — разд. 13.7; с `adsorption` умножается на функцию повреждения $perm\_damage(\sigma_v/(\text{PERM\_SMAX}\,m_0), \beta, \gamma)/D_0$, где $\sigma_v = (g_a + g_r)/\rho_{ad} + (q_{ada} + q_{adr})\Delta t$, $D_0$ — повреждение от начального удержания. Пол $k \ge 10^{-8}k_0$: нулевая подвижность вырождает матрицу давления.

## 13.6. Профили скоростей частиц (`_particle_rows`) и перенос к стенке

Для частицы радиуса $a = d_p/2$ порог $r_{pass} = a/\gamma$. Блокирование ($r < r_{pass}$): $b = S_o^{eff}\,w\,\dfrac{6\beta}{d_p^3}\,U_{m2}\,snow\,r^4$, $u = 0$. Сужение ($r \ge r_{pass}$): $b = 0$, $u = -S_o^{eff}w\,snow\,\left(Lev + u_g\right)$, где без `wall_transport` $Lev$ — Левек по броуновской диффузии ($D_p$ умножается на `diff_mult·kin[DIFF_MULT]`, $u_g = 0$); с `wall_transport` — $Lev(U_{m2}r^2, r, D_{tot})$ с полным коэффициентом $D_{tot} = D_{Brown} + c_{shear}\varphi_v^2\dot\gamma_wa^2$ (сдвиговая дисперсия, Eckstein et al., 1977; $\dot\gamma_w = 4U_{m2}r$) и стоксово оседание $u_g = \text{GRAV\_EFF}\cdot 2a^2\Delta\rho g/(9\mu)$. Вязкость диффузии $\mu_p$ либо (при `gel_hindered_diffusion`) $\mu_o = \mu_p/\Phi$.

## 13.7. Стеночные стоки и сеть пор

**Стеночная кристаллизация** (`wax_kinetics`, `_wall_crystallization`). Два параллельных пути первого порядка — в объеме (`K_CRYST`) и на стенке (`K_WALL`) — делят пересыщение; доля, уходящая на стенку, **точная** за шаг:

$$\mathrm{frac} = \frac{k_{wall}}{k_{wall} + k_{cryst}}\left(1 - e^{-(k_{wall} + k_{cryst})\Delta t}\right). \qquad (13.4)$$

Стоки по группам $\mathrm{frac}\cdot\max(weq_k - W_{s,k}, 0)$; возврат $\min(\text{total}\,\mathrm{mso}/\Delta t,\ \text{total}\,\mathrm{mso}_{dt})\,\rho_o/\rho_p$. С `thermal_nonequilibrium` ($T_s < T$): равновесие при температуре породы, массоотдача $k_f = 2D_m/d_g\cdot6(1 - m)/d_g/\mathrm{mso}$, доля $1 - e^{-k_f\Delta t}$. С `deposit_dissolution`: растворение осадка в недосыщенной нефти — равновесие гипотетической нефти вместе с осадком, $\mathrm{frac}_d = 1 - e^{-K_{wall}\Delta t}$, отрицательный сток. **Старение** (`deposit_aging`, `_aging`): $\text{rate} = v_{gel}\,\text{AGE\_RATE}\max(\text{AGE\_CMAX} - C, 0)$, $C = \sum D/\rho_p/v_{gel}$, источник — растворенный парафин насыщенных групп, не больше $\mathrm{mso}_{dt}\,w^{dis}_{sat}\rho_o/\rho_p$. Стеночная кристаллизация и старение берут из одного пула растворенного парафина, каждая со своим запасом, общего бюджета нет — перерасход гасит только зажим $w \ge 0$ в `components_equation`.

**Сеть пор и горл** (`pore_network`). Проводимость ячейки — не сумма по каналам пучка, а эффективная проводимость сети горл. Горло радиуса канала $r$ с отложением толщиной $h$: $r_t = \text{NET\_GAMMA}\,(r + h) - h$, проводимость $g = (r_t/r_{max})^4$, вес $w = \varphi\,dr_{cv}$; закрытая доля $w_{blocked} = \max(1 - \sum w, 0)$; $k/k_0 = \max(g_m/g_{m0}, 10^{-8})$, где $g_{m0}$ — исходной сети (одна на все ячейки, считается раз за шаг до `prange`). $g_m$ — корень уравнения эффективной среды (Kirkpatrick, 1973) с координационным числом $z$ = `NET_Z`:

$$\sum_iw_i\frac{g_m - g_i}{g_i + (z/2 - 1)g_m} + \frac{w_{blocked}}{z/2 - 1} = 0. \qquad (13.5)$$

Функция монотонна по $g_m$, корень ищется **бисекцией по $\ln g_m$** на $[\ln g_{top} - 40, \ln g_{top}]$, не более 80 итераций (досрочный выход при неподвижной точке в машинном представлении — результат тот же); если на нижнем конце $f \ge 0$ — возврат 0 (ниже порога протекания $2/z$). При одинаковых горлах $g_m = g\,(p - 2/z)/(1 - 2/z)$ ($p$ — доля открытых): проводимость исчезает на пороге протекания, а не при закрытии всех каналов, как у пучка. Пористость и тождество пористости сеть не меняет. Сверено с прямым расчетом случайной решетки (0.008 по $k/k_0$).

## 13.8. Порог выноса и гель-отложение

`entrainment_threshold`: без `deposit_aging` порог равен `ENT_TAU`; иначе $\tau_{cr} = \text{ENT\_TAU}\cdot\max(\tau_y(C), \tau_0)/\tau_0$ с $C = \min(\sum D/\rho_p/v_{gel}, 1)$ и $\tau_0 = \tau_y(\text{AGE\_C0})$ (предел текучести геля по доле парафина в отложении, `Gel.yield_stress`).

## 13.9. Глубинная фильтрация (`deposition_model = 'filtration'`) и $k(\sigma)$

`calc_filtration`: $\varphi$ не меняется (`new_fi = fi`). Скорость осаждения $\text{def\_rate} = \text{FILT\_KD}\cdot\mathrm{mso} + \text{FILT\_KPL}\cdot u_o$, $u_o = \lambda_o|\nabla p|$; кристаллы $\min(\text{def\_rate}\,w_{ps}\rho_o/\rho_p,\ \mathrm{mso}_{dt}w_{ps}\rho_o/\rho_p)$; вынос $\min(\text{FILT\_KE}\,\max(u_o - \text{FILT\_UCR}, 0)\,D/\rho_p,\ D/\rho_p/\Delta t)$; асфальтены — аналогично с ограничителем по $w_{af}$ и $w_r$; $q_{p2} = 0$; стеночные стоки те же. Пористость $m^{n+1} = m - \sum q\Delta t$, $\sigma_v = m_0 - m^{n+1}$, $k = k_0\cdot\text{perm}(\ldots)$; `perm_model`: `kozeny_carman`, `power`, `damage`, `surface` (`Kinetics_math`). Пола на $k$ в этом режиме нет.

# 14. ГЕЛЬ И ВЯЗКОСТЬ НЕФТИ

## 14.1. Вязкость жидкой основы и суспензии

$\mu_L(T) = \mu_{ref}\exp[(E_a/R)(1/T - 1/T_{ref})]$ (Аррениус через опорную точку: уровень и крутизна — независимые параметры); кристаллы увеличивают вязкость как суспензия, $\varphi_v = (w_{ps}/\rho_p)/(w_{ps}/\rho_p + (1 - w_{ps})/\rho_o)$:

$$\mu = \mu_L\left(1 - \frac{\varphi_v}{\varphi_{max}}\right)^{-2.5\varphi_{max}}\ \ (\text{Кригер–Догерти}),\qquad \mu = \mu_L e^{D\varphi_v}\ \ (\texttt{wax\_viscosity} = 1,\ \text{Pedersen, Rønningsen}). \qquad (14.1)$$

Кригер–Догерти расходится при $\varphi_v \to \varphi_{max}$, поэтому доля ограничена сверху $0.99\varphi_{max}$. `calc_mu_p` умножает на $\exp(\alpha_p(p - P_{ref}))$ при `pressure_viscosity` (Барус).

## 14.2. Гель (`gelation`)

1. **Предел текучести** (`Gel.yield_stress`): $\tau_y = \text{mult}\cdot\tau_{ref}\left(\dfrac{\varphi - \varphi_{gel}}{\varphi_{ref} - \varphi_{gel}}\right)^n$ при $\varphi > \varphi_{gel}$, иначе 0. $\varphi$ — доля твердого **в поре** (`pore_solid_fraction`): $\varphi = (v_{oil}\varphi_{susp} + w\,v_{dep})/(v_{oil} + w\,v_{dep})$, $w$ = `gel_deposit_weight`; взвеси в потоке почти нет (она сразу оседает), а осадок и есть гель. Объем осадка $v_{dep}$: с кинетикой $\sum D_k/\rho_p$; без нее $m_0 - m - (D_{af} + D_r)/\rho_{ad}$, не меньше нуля.
2. **Множитель течения Букингема–Райнера.** Течение геля в пучке капилляров: $F(\xi) = 1 - \frac43\xi + \frac13\xi^4$ при $\xi = \tau_y/\tau_w < 1$, иначе 0; $\tau_w = r|\nabla p|/(2\eta)$. Равновесный множитель подвижности — квадратура по узлам, **корней не ищется**: $\Phi_{eq} = \sum w_4\varphi F(\xi)/\sum w_4\varphi$ (при $\tau_y \le 0$ или нулевой сумме — 1).
3. **Релаксация** (тиксотропия): $\Phi = \Phi_{eq} + (\Phi - \Phi_{eq})e^{-\Delta t/t_{gel}}$ — без нее запаздывание давало бы колебания; множитель $e^{-\Delta t/t_{gel}}$ считает `_swap_time_steps`.
4. **Эффективная вязкость:** $\mu_o = \mu_p/\max(\Phi, \text{gel\_mobility\_min})$ (0.05; нижняя граница держит матрицу давления положительно определенной). Через $\mu_o$ гель согласованно попадает в матрицу, продуктивность скважин и перетоки. Градиент давления — предыдущего слоя; `Gel.oil_viscosity` по полям **нового** слоя ($new\_T$, $new\_w_{ps}$, $new\_S$, $new\_m$, $\varphi$) зовет `_swap_time_steps`, до смены ссылок.

# 15. ШАГ ПО ВРЕМЕНИ

## 15.1. Условия устойчивости

Три ограничения считаются прямо в `_equations_loop` по расходам с давлением нового слоя ($CFL$ = `CFL_target` = 0.8):

1. по насыщенности: $\Delta t \le CFL\,m\,V/(F'_{max}\,Q_{out})$, $F' = dF_w/dS$ — по таблице (разд. 15.2); локальный $F'_{ij}$ считается (`_cell_dfw`), только если оценка по глобальному максимуму уже ниже набранного минимума;
2. по переносу компонентов: $\Delta t \le CFL\,m(1 - S)V/Q_{o,out}$ (при переносе компонентов);
3. по температуре: $\Delta t \le CFL\,\psi V/T_{out}$, $T_{out}$ — тепловой отток (конвекция плюс кондукция); при LTNE $\psi$ — полная.

Осаждение шаг не ограничивает. Затем `_calc_dt` добавляет скважины ($q_{out} = Q_{out} + |q_t|$, состояние втекающей воды — верх таблицы $F_w = 1$ у нагнетательной, $S$ ячейки у добывающей) и применяет рост:

$$\Delta t^{n+1} = \min\left(\max(\Delta t_{new}, \Delta t_{min}),\ \Delta t^n\cdot dt\_growth,\ \Delta t_{max}\right). \qquad (15.1)$$

`dt` из `constants.py` — только стартовый шаг; по умолчанию `dt_max = dt` (шаг не растет выше стартового, поэтому рост важен только после падения), `dt_min = 10^{-3}dt`, `dt_growth` = 1.2.

## 15.2. Таблица $dF/dS$

`_calc_dfw_table` строит огибающую $|dF_w/dS|$, **которую нельзя занижать** (иначе шаг окажется слишком большим). Сетка по насыщенности — $10\cdot$`dfw_bins`$+1$ узлов на $[S_{min}, S_{max}]$ (при `wettability` диапазон расширен смесями ОФП, $\omega \in \{0.25, 0.5, 0.75, 1\}$); $F_w$ — Баклей–Леверетт $f_w/(f_w + f_o\mu_w/\mu_o)$ при $\mu_w(T)$, $\mu_o(T, w_{ps})$ для 11 температур между минимальной (`init_T`, $T_{inj} - A$) и максимальной и для $w_{ps} \in \{0, init\_Wp\}$; производная — `numpy.gradient`; огибающая — поэлементный максимум. Дополнительные проходы — множители вязкости: Барус по минимуму и максимуму давления (`init_p`, забойные), гель — множитель $1/$`gel_mobility_min` (применяется ко всем множителям Баруса). Таблица: `dfw[0]` — левый край, `dfw[1]` — масштаб $\mathrm{bins}/(S_{hi} - S_{lo})$, `dfw[2]` — глобальный максимум, `dfw[3 + b]` — максимум по бину. Секущая $F_w$ не больше производной, поэтому оценка консервативна.

# 16. ОБМЕН СЛОЕВ, СОХРАНЕНИЕ, ЛОГИРОВАНИЕ

**Обмен слоев** — сменой ссылок (`Solver._swap_refs`): $new\_X$ становится текущим, освободившийся буфер — новым (`S`, `T_0 ← T ← new_t`, вязкости, `Wp`, `Wps`, `k`, `m`, `qp1`, `qp2`, `Hl`, `Wc`, `Ws`; $\varphi$ и $h$ при кинетике). Поэтому уравнение обязано писать $new\_X$ присваиванием в каждой ячейке каждого шага, а ссылки на поля нельзя держать между шагами (`a = solver.S` перед циклом устареет). Что пишется не везде (`fi`, `h_sloy`, `Ur`, `Ub` — только при кольматации; `kx`) и вязкость нефти с гелем/Барусом копирует/считает параллельный `_swap_time_steps` — он зовется до смены ссылок. Простое ядро копирует $\varphi$, $U_r$, $U_b$ только выше порога $w_{ps} > w_{min}$ (и $\varphi$ при сужении флокулами).

**Сохранение.** Слои дозаписываются в один открытый файл `outputs/results_wp=…/layers.pkl` с шагом `sol_time_step`; по окончании (в `finally`, в том числе при `KeyboardInterrupt`) файл закрывается, слои склеиваются (`convert_pkl_files`) в `outputs/data/Wp=…_processed_data.pkl`, промежуточная папка удаляется. Функция $\varphi$ выгружается одной кривой по радиусам из точки `FI_PROBE`, а не полем $(N_x, N_y, N_r)$. Склейка держит все слои разом — единственное место выгрузки, которое упирается в память на больших сетках.

**Логирование** (`_logging_solution`) — по тому же расписанию, что и сохранение, и **до** `_swap_time_steps`.

## 19.2. Дискретизация в пространстве

**Метод.** Центрально-ячеечный метод конечных объемов на равномерной прямоугольной сетке. Уравнение баланса интегрируется по ячейке; поток через грань — значение на грани, умноженное на площадь; сумма потоков по четырем граням входит в баланс ячейки. Благодаря этому каждая сеточная схема консервативна: поток, ушедший из одной ячейки, целиком пришел в соседнюю (на границе — в ГУ).

**Аппроксимации на грани.**

| Величина | Аппроксимация | Почему |
|---|---|---|
| проводимость по давлению | гармоническое среднее суммарных подвижностей $\mathrm{mid}(\lambda_c, \lambda_n)$ | точна для последовательных сопротивлений, при разрыве $k$ или $S$ дает поток через меньшую подвижность; при нулевой подвижности одной из ячеек поток нулевой |
| доли фаз $f_\alpha$, состав $w_c$, температура и энтальпия нефти | апвинд: значение в ячейке с большим давлением | схема первого порядка, монотонна; гармоническое среднее обнулило бы поток из промытой водой ячейки |
| теплопроводность | $\mathrm{mid}(\lambda_{h,c}, \lambda_{h,n})A_f/h_f\cdot(T_n - T_c)$ | то же, что для проводимости |
| $\vert\nabla p\vert$ для скоростей в порах и геле | центральная разность $(p_{i+1} - p_{i-1})/(2h)$ внутри, односторонняя на границе, ноль по оси с одной ячейкой | отдельная оценка в центре ячейки, не потоки граней |
| граница | фиктивная ячейка на расстоянии $h/2$: Дирихле — значение, Нейман — $F_c + g\,h/2$ | поток $T_b(F_b - F_c)$ с проводимостью по $h/2$ |

**Дискретный оператор давления.** Для внутренней ячейки $(i,j)$ уравнение (5.1) записывается как

$$\left(T_E + T_W + T_N + T_S\right)p_{i,j} - T_Ep_{i+1,j} - T_Wp_{i-1,j} - T_Np_{i,j+1} - T_Sp_{i,j-1} = q_{i,j}, \qquad (19.1)$$

$T_E = \mathrm{mid}(\lambda_{i,j}, \lambda_{i+1,j})\,h_yh/h_x$ и аналогично для остальных граней ($T_N$, $T_S$ — с множителем $h_xh/h_y$). Матрица симметрична, потому что проводимость грани, общей для двух ячеек, одна и та же с обеих сторон. На границе недостающий член заменяется диагональным вкладом $T_b$ (Дирихле) или правой частью (Нейман).

**Порядок схемы.** Давление — центральные разности, второй порядок на гладких коэффициентах. Перенос ($S$, $w_c$, $T$) — первый порядок. Эффективная численная диффузия явной схемы против потока для скорости $u$ и шага $h$ (модифицированное уравнение):

$$D_{num} = \frac{uh}{2}\,(1 - C),\qquad C = \frac{u\,\Delta t}{h}, \qquad (19.2)$$

то есть фронт размазывается на величину порядка ячейки, и тем меньше, чем ближе число Куранта к единице (`CFL_target` = 0.8). Перенос по оси радиусов $\varphi(r)$ — тоже апвинд первого порядка с шагом $dr_{cv}$: сужение капилляров отражается переносом функции распределения по сетке, при этом размазывание по $r$ мало, поскольку переносимая величина гладкая.

**Устойчивость и монотонность явной части.** Для ячейки с пористым объемом $mV$ явная схема против потока дает новое значение как выпуклую комбинацию старых, если выполнено

$$\Delta t \le \mathrm{CFL}\,\frac{m\,V}{F'\,Q_{out}}, \qquad (19.3)$$

где $Q_{out}$ — суммарный объемный отток ячейки, $F' = dF_w/dS$. Это ровно первое из трех условий разд. 15.1; для переноса компонентов $F' = 1$ и объем $mS_oV$, для температуры — $\psi V$ и тепловой отток. Условие записано через **отток ячейки**, а не через одну грань, поэтому оно учитывает двумерность без поправки.

## 19.3. Дискретизация по времени и расщепление

**IMPES.** Давление решается на новом слое при коэффициентах слоя $n$; затем явные уравнения шагают по перетокам, рассчитанным по новому давлению. Порядок по времени — первый. Нелинейных итераций между давлением и насыщенностью нет; согласованность держит малый шаг по Куранту.

**Расщепление внутри ячейки.** Процессы разных характерных времен не решаются совместно, а применяются последовательно за один шаг; порядок зафиксирован (разд. 4.1) и повторяет порядок вычислений постановки:

1. гидродинамика: перетоки → насыщенность;
2. кольматация (пучок): кинетика скоростей, неявная прогонка по радиусам, пористость;
3. перенос компонентов со стоками нового слоя;
4. мгновенное равновесие парафина → релаксация флокул, агрегация, адсорбция (кинетика на шаге);
5. энергия, последней, потому что ей нужны $m$, $S$, $w_p$ нового слоя (скрытая теплота и теплоемкость).

Ошибка расщепления — первого порядка по $\Delta t$. Если в ядре осаждения быстрые процессы (стоксовская диффузия частиц на порядки быстрее переноса), их стоит брать неявно или точно, а не ограничивать шаг. Поэтому:

- сток парафина зажат **подводом** (`lim_w`, `lim_a`) вместо ограничения шага;
- блокирование взято неявно в прогонке по радиусам;
- адсорбция — неявно по концентрации в нефти ячейки;
- релаксации (флокуляция, кристаллизация, доля стенки, Смолуховский, тиксотропия геля) — **точным решением ОДУ** за шаг: безусловно устойчиво, при $\Delta t \to 0$ совпадает с явным шагом.

**Что на каком слое.** Подвижности, вязкости, температура апвинда, доли фаз — слой $n$; давление, стоки $q_{p1}$, $q_{p2}$, $m$, $S$ в знаменателях — слой $n+1$. Лаг в один шаг: скорости блокирования и сужения простого ядра ($U_r$, $b$) читаются с прошлого шага; кинетическое ядро считает их по текущему слою.

### Псевдокод шага

```text
ШАГ(t):                                          # слой n -> n+1, параллельно по ячейкам там, где указано
  lam_o, lam_w, lam_h ← ПОДВИЖНОСТИ(S, k, mu_o, mu_w)               # слой n, один раз
  M, rhs ← МАТРИЦА(lam, ГУ)                    # три диагонали, M = -A, SPD
  J ← ПРОДУКТИВНОСТЬ_СКВАЖИН(k, S, lam)         # единственное место формулы Писмана
  для скважины w: если режим p: M.diag += J_t; rhs += J_t*p_w
                  иначе       : rhs += q_t
  x0 ← ПРОЕКЦИЯ(p_hist, M, rhs)                 # Fischer
  p  ← PCG_MG(M, rhs, x0, rtol=1e-10)
  дебиты, eta ← J*(p_w - p_ячейки), BL(S_ячейки)
  src_S, src_T, src_Qo ← из дебитов

  параллельно по ячейкам:                       # проход 1
      |grad p|, Um_r2 ← ГРАДИЕНТ(p)
      потоки F, оттоки ← ПЕРЕТОКИ(p, lam, S, T, w)             # апвинд по знаку F
      если кинетика: сток, phi', m', k' ← calc_deposition(...) # неявная прогонка по r
  если не кинетика, параллельно по активным ячейкам:            # проход 2
      Ur, Ub ← calc_velocities_h ; phi', m', k', q ← calc_qp_m_k_fi

  параллельно по ячейкам:                       # проход 3
      S'   ← НАСЫЩЕННОСТЬ(S, m, m', потоки воды, src_S)
      w_c' ← ПЕРЕНОС(w_c, потоки нефти, src_Qo, стоки нового слоя) / (m' * S_o')
      (w_dis, w_sus, Hl) ← РАВНОВЕСИЕ(w', T, p)                  # или релаксация при wax_kinetics
      af', N_F' ← ФЛОКУЛЯЦИЯ, АГРЕГАЦИЯ
      T'   ← ЭНЕРГИЯ(psi', потери тепла, скрытая теплота) [+ LTNE-обмен]
      mu_w', mu_o' ← f(T', w_ps')
      dt_ячейки ← min(Курант по S, по w_c, по T)
  dt_next ← min(max(dt_new, dt_min), dt*dt_growth, dt_max)       # включая скважины
  ОБМЕН_СЛОЕВ()                                  # смена ссылок X <-> new_X
```

### Псевдокод PCG с многосеточным предобуславливателем

```text
PCG_MG(M, b, x):
    r ← b - M*x ; z ← V(r) ; d ← z ; rz ← r·z
    пока |r| > rtol*|b| и it < maxit:
        q ← M*d ; a ← rz/(d·q) ; x += a*d ; r -= a*q
        z ← V(r) ; rz' ← r·z ; d ← z + (rz'/rz)*d ; rz ← rz'
    # в коде три слитых прохода: q = M*z + beta*q вместо M*d

V(r), уровень L:
    если L грубейший: вернуть ХОЛЕЦКИЙ(M_L, r)
    x ← ПРЕД_СГЛАЖИВАНИЕ(красно-черный Гаусс-Зейдель)
    r_c ← P^T (r - M*x)                       # свертка невязки на блоки 2x2
    x_c ← V_{L+1}(r_c)
    x += s*P*x_c                              # s = p_mg_scale = 1.7
    x ← ПОСТ_СГЛАЖИВАНИЕ(зеркальный порядок)  # симметрия V-цикла
```

### Псевдокод переноса компонентов в ячейке

```text
ПЕРЕНОС(ячейка):
    mso ← m*S_o ; mso' ← m'*S_o'
    для компонента c:
        acc_c ← mso*w_c - dt*s_c                       # s_c: стоки нового слоя
        acc_c += dt/V * (sum_грани F_o,f * w_c,up + q_o*w_c)
    если mso' <= 1e-12: все доли ← 0 ; выход
    w_c' ← clamp(acc_c / mso', 0, 1)
    если wax_kinetics: s_k ← релаксация(s_k, равновесная взвесь, K_CRYST|K_DISS)
    иначе: (w_dis, w_sus, Hl) ← sle_split(w_wax', T', p)
    w_max ← asph_soluble(...)                        # Хиршберг или таблица Nghiem
    af ← floc_relax(af, max(a_tot - w_max, 0), dt)   # точная экспонента
    если asph_aggregation: N_F ← smoluchowski_step(N_F, ...)
```

### Псевдокод flash пар — жидкость

```text
FLASH(z, T, p):
    w ← STABILITY(z, T, p)                  # Michelsen; старт Вильсона; sum W > 1+1e-7 -> неустойчиво
    если w = None: вернуть одну фазу        # метка по корню Z
    K ← max(w/z, 1e-200)
    повторять до 500 раз:
        beta ← RR(z, K)                     # brentq, граничные случаи без поиска
        x ← z/(1 + beta*(K-1))
        K_new ← exp(ln phi_L(x) - ln phi_V(K*x))
        stop если max |ln(K_new/K)| < 1e-12
    вырождение в одну фазу при max|K-1| < 1e-4 или beta у границ
```

# 20. ОГРАНИЧЕНИЯ МЕТОДА

1. **Явные коэффициенты давления.** Подвижности и вязкости со слоя $n$; сильная нелинейность (резкий фронт геля, быстрая смена температуры) ограничивается только шагом Куранта.
2. **Первый порядок по пространству и времени** для переноса: численная диффузия фронтов порядка размера ячейки; для острых фронтов нужна сетка.
3. **Итерации термодинамики без ускорения.** Тест устойчивости и flash — простые подстановки без DEM/GDEM и без проверки сходимости после `maxiter` (1000 и 500); вблизи критической точки возможен медленный счет. Расслоение жидкость–жидкость отключено правилом Кея (разд. 11.4). Расчет PR идет при импорте, не в ячейке.
4. **Таблицы заморожены на исходной нефти.** Изменение состава жидкости по ходу вытеснения (выпавший парафин, газ) в $x^{sat}$ и $n_{gas}$ не учитывается; предел $w_{max}$ Nghiem не зависит от состава ячейки.
5. **Жадный active-set без итераций** точен для чистых твердых фаз (multi-solid) и не годится для твердого раствора — для него `ss_split` с внутренними итерациями; расслоение твердых растворов не поддержано.
6. **Бисекция WAT** предполагает монотонность насыщения по температуре.
7. **Общий пул растворенного парафина** у стеночной кристаллизации и старения: каждая со своим запасом, суммарный перерасход гасит только зажим $w \ge 0$.
8. **Лаг скоростей простого ядра** — один шаг; кинетическое ядро лага не имеет.
9. **Калибровка $\delta_a$ и рантайм** считают газ по-разному при выключенном `wax_pressure` (разд. 12.1).
10. **Потери тепла VW**: производная $T$ накоплена за прошлый шаг и делится на текущий (расхождение до `dt_growth`); автомодель на 3.3 % ниже точного отклика.
11. **Гелирование:** нижняя граница подвижности `gel_mobility_min` — численное, а не физическое ограничение.
12. **Решатель давления** при полном вырождении подвижностей (нулевая сумма в строке) — ошибка, а не регуляризация; пол $k \ge 10^{-8}k_0$ в ядре кинетики это предотвращает.
