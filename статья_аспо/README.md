# статья_аспо

Статья о механизмах кристаллизации и осаждения парафинов, смол и асфальтенов: сопоставление модели со всеми опытами
(Sutton & Roberts, Li et al., Sandyga и др.), общий набор параметров, термодинамика и реология против независимых
измерений, причины оставшихся расхождений. Вторая часть работы - статья о термических процессах в `../статья_твт/`.

| Файл | Что это |
|---|---|
| `article.md` → `article.docx` | Текст статьи. Числа и таблицы - подстановки `{{КЛЮЧ}}` из `results/numbers.json`; рисунки, таблицы и источники сборка перенумеровывает по первому упоминанию (`md_to_docx.py::renumber`), подписи - под рисунками |
| `make_article.py` | Рисунки и числа **обеих** статей по `experiments/results/*.json`, `experiments/уравнение_состояния/results.json` и `../статья_твт/results/*.json`: `figures/crys_f*` здесь, `term_f*` - в `../статья_твт/figures`; в `numbers.json` и `metrics.md` каждой статьи попадают только ее ключи `{{КЛЮЧ}}` |
| `figures/crys_f*.tif`, `.png` | Рисунки статьи (600 dpi, серые) |
| `results/numbers.json`, `metrics.md` | Числа статьи (формат подстановки и список для чтения) |
| `CHANGES.md` | Что изменено в модели и данных при разделении работы на две статьи; метрики «было → стало» |
| `материалы/` | `исправленные уравнения.docx` - постановка и вычислительная схема с правками автора (раздел модели обязан ему соответствовать); `full_review.pdf` - обзор по осаждению парафинов, асфальтенов и смол, на который ссылаются `paraphin/` и `docs/` |

## Пересобрать

```bash
python experiments/run_all.py --quick                  # сравнения с опытами (если менялся код пакета)
python experiments/unified.py                          # общий набор параметров на все керны
python experiments/уравнение_состояния/compare.py      # термодинамика против опытов
python статья_аспо/make_article.py                     # рисунки и числа
python md_to_docx.py статья_аспо                       # article.docx
```
