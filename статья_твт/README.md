# статья_твт

Статья для журнала «Теплофизика высоких температур» о термических процессах при заводнении: теплообмен с вмещающими
породами, тепловые эффекты кристаллизации, верификация тепловой части (решение Ловерье, MRST), один керновый опыт
(Sandyga), полевые варианты. Вторая часть работы - статья о кристаллизации и осаждении в `../статья_аспо/`.

| Файл | Что это |
|---|---|
| `article.md` → `article.docx` | Текст статьи. Числа и таблицы - подстановки `{{КЛЮЧ}}` из `results/numbers.json`, руками не набираются. Журнальная сборка: подписи к рисункам с новой страницы после литературы (правила ТВТ, разд. II.1-3) |
| `run_thermal.py` | Полевые варианты (элемент заводнения, 5 лет, пласт 55 C): по одному фактору от базового - температура закачки, теплообмен с кровлей и подошвой, нефть без парафина, гель, удержание смол и асфальтенов, скрытая теплота, кинетика кристаллизации, давление в WAT, тепловое неравновесие, сетки. Кинетика - из подборов по керну Li et al. (`experiments/params.json`). Результат - `results/thermal.json`, полные расчеты - `outputs/data/thermal_<вариант>__*` |
| `verify_heat.py` | Верификация тепловой части: решение Ловерье, сходимость по сетке, MRST geothermal с эффектом Джоуля - Томсона и без -> `results/verify_heat.json` |
| `romashkino.py` | Обращение решения Ловерье по трем контрольным скважинам Ромашкинского месторождения (Sandyga et al., 2021) при перебираемой теплопроводности пород -> `results/romashkino.json` |
| `figures/term_f*.tif`, `.png` | Рисунки статьи (600 dpi, серые); строит `../статья_аспо/make_article.py` |
| `results/` | Результаты расчетов (`thermal.json`, `verify_heat.json`, `romashkino.json`) и числа статьи (`numbers.json`) |
| `материалы/` | `PravilaTVT.pdf` - правила журнала, `rules_checklist.md` - чек-лист пунктов правил |
| `metrics.md` | Числа статьи списком, для чтения; пишет `make_article.py` |

## Пересобрать

```bash
python статья_твт/verify_heat.py             # ~5 мин
python статья_твт/romashkino.py              # секунды
python статья_твт/run_thermal.py             # полевые варианты, ~20 мин на вариант; --metrics - только показатели
python статья_аспо/make_article.py           # рисунки и числа обеих статей
python md_to_docx.py статья_твт              # article.docx; --lint статья_твт/article.docx - проверка формул и шрифтов
```
