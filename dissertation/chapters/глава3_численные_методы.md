# Глава 3. Численный метод и программный комплекс — заготовка

Специальность 1.1.9: численный метод — средство исследования (направление 19 паспорта «… численные и комбинированные
методы исследования уравнений континуальных … моделей многофазных сред»), а не самостоятельный результат. Глава
сжимается до 10–15 с.: схема, её свойства (консервативность, устойчивость, ограничение стока подводом), верификация
на аналитических решениях. Детали решателя давления и производительности — в приложение. Новизну по численной части
формулировать как метод исследования задачи, а не как комплекс программ. Подробности реализации — `CLAUDE.md`, `docs/решатель_давления.md`,
`docs/PERFORMANCE_FINDINGS.md` проекта; литература — обзор, разд. 11.

## 3.1. Дискретизация

- МКО на регулярной сетке, TPFA, разность против потока для подвижностей [@m:aziz1979; @m:peaceman1977;
  @10.1137/1.9780898718942]. Консервативность по каждому компоненту — обязательное требование: ошибка баланса
  парафина прямо искажает массу осадка.
- Сетка радиусов пор (пучок): интегралы по отрезкам точно, перенос функции распределения по оси радиусов прогонкой
  с неявным слагаемым блокирования (иначе большое b·dt уводит φ(r) в минус).

## 3.2. Схема по времени

- IMPES [@10.2118/978-g; @10.2118/1518-g]; уравнение давления из суммы балансов фаз (обобщённый IMPES Коутса —
  [@10.2118/65092-pa]).
- Адаптивный шаг по трём условиям Куранта (насыщенность, перенос компонентов, температура); критерий устойчивости —
  [@10.2118/84924-pa]. Новое: прежний критерий проекта был размерным и считался один раз — исправлено.
- Порядок вычислений внутри шага повторяет постановку: перетоки по текущему слою → кольматация → насыщенность →
  перенос компонентов (делится на m·S_o нового слоя) → температура (теплота кристаллизации по новому слою).
- Жёсткая кинетика осаждения: ограничение стока подводом с учётом явного оттока, а не уменьшение шага (обзор, разд.
  11.2, «специфика АСПО»). Тождество пористости (q_p1 + q_p2 + …)·dt = m − m_new выполняется точно.

## 3.3. Скважины

- Писман [@10.2118/6893-pa; @10.2118/10528-pa], скважины неявны по давлению; один источник формулы продуктивности
  для матрицы и для дебитов (равенство закачки и отбора тождественно).
- Скин не задаётся, а возникает из поля k(r, t); сравнение с формулой Хокинса [@10.2118/732-g].

## 3.4. Решатель уравнения давления

- PCG [@10.6028/jres.049.044] с многосеточным V-циклом: агрегация 2×2 по Галёркину, красно-чёрный Гаусс–Зейдель,
  масштабирование грубой поправки [@10.1007/bf02238488; @m:notay2010]; грубые операторы пересобираются по правилу цены.
- Начальное приближение — проекция на разности прошлых решений с минимумом ошибки в энергетической норме
  [@10.1016/s0045-7825(98)00012-7]: 0.5–0.8 итерации на шаг против 1.7 у квадратичной экстраполяции.
- Сравнение с альтернативами (ленточный Холецкий, двусторонняя факторизация, AMG): `docs/PERFORMANCE_FINDINGS.md`.
- Открытый вопрос из обзора: влияние контраста проницаемости 10³–10⁶ при закупорке на сходимость (обзор, 11.7).

## 3.5. Термодинамика в ячейке

- Таблицы по (T, P) вместо flash в ячейке, билинейная интерполяция; дисковый кэш таблиц. Альтернативы в литературе —
  OBL (DARTS) и табулирование равновесия (обзор, разд. 4.5).

## 3.6. Программный комплекс

- Python + Numba (JIT, кэш на диск) [@10.1145/2833157.2833162]; ядра — модульные функции с массивами, параллельные
  по ячейкам; ловушки (гонка общего скретч-буфера, кэш двух версий функции) — `CLAUDE.md`.
- Сопоставление с открытыми платформами (MRST, OPM, DuMux, DARTS, Jutul) — обзор, табл. 11.1; эталоны MRST для
  гидродинамики [@10.1017/9781108591416].

## 3.7. Верификация

- Методология V&V [@10.1017/cbo9780511760396].
- Аналитика: Баклей–Леверетт [@10.2118/942107-g]; Ловерье [@10.1007/bf03184614]; Шуман для LTNE
  [@10.1016/s0016-0032(29)91186-8]; аналитические решения кинетики (Смолуховский, Ленгмюр) — `tests/test_kinetics_math.py`.
- Балансы: масса каждой группы до 1e-16, тождество пористости, равенство закачки и отбора; побитовые регрессии; два
  прогона подряд совпадают побитово (нет гонок).
- Эталоны MRST (`tests/mrst_tests`); сеточная сходимость; производительность на сетках 50×50 и больше.

## Что заявлять как новое

Многосеточный PCG с проекцией начального приближения для IMPES-задачи с кольматацией; ограничение скорости осаждения
подводом как способ интегрировать жёсткую кинетику без уменьшения шага; консервативная схема переноса функции
распределения пор.
